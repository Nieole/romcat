# 03 — 算得出来的四样数由一条命令写，门禁核对

**What to build:** 维护者不必再手抄那几个会随票变的数。**测试条数、测试目标数、票数、
ADR 份数**由一条命令写进带标记的位置；它们过期时**门禁报红，并告诉他对的那个数**。

收挂单 `Q380`（那一族数第三次被记：`Q198`、`Q268`、`Q380`）。

**Blocked by:** 无 —— 可立即开工

**Status:** done

⚠️ **判据：一条命令算得出来的数，才准写成断言。** 只管那四样。
**真库那些数不进这个机制**（机器碰不到）——它们归票 `04`。

⚠️ **标记形状：单行标记、值紧跟其后**（Markdown 用 HTML 注释、TOML 用 `#` 注释，同一形状）。
成对的区段标记要处理「区段里被人手改过」，而单行标记的**替换与核对是同一条正则**。

⚠️ **两个动作**：`--write` 改写、`--check` 核对；门禁跑的是 `--check`，
**报错里必须带上对的那个数**，这样人不必自己去数。

⚠️ **`--check` 得自己跑一趟「列出全部测试」**：门禁那几条走的是继承 stdio 的方式、
**不捕获子进程输出**，没法从测试那一趟里顺手把数捞出来。这一条排在测试之后，编译缓存是热的。

⚠️ **计数规则写死**：票数按**行首锚定**的 `Status:` 行数——松一点的匹配会把票末尾正文里
出现的 `done` 也算进去（实测撞过：松匹配数出 88，锚定数出 87）。

## 收尾（2026-09-22）

**做了什么：** 那四样（测试条数、测试目标数、票数、ADR 份数）由 `cargo xtask numbers --write`
写进 `README.md` 里带标记的位置，门禁多一条 `cargo xtask numbers --check` 核对，排在 `test`
之后（它要的那份编译缓存由 `test` 热着）。**第二处手抄的全删了**：`README.md` 那句「少跑
123 条（1,692 而不是 1,815）」与 `crates/gui/Cargo.toml` 里同一对数，一并换成「少跑一百多条」
——理由与代价记在挂单 `Q1160`。四样今天**各只有一处**。

**标记形状：** 单行、值紧跟其后，注释开头 ＋ `数:` ＋ 名字（Markdown 是 HTML 注释、TOML 是
`#` 注释，同一形状同一段代码读）。⚠️ **注释开头不能省**：光认 `数:` 会撞上散文里的
「总数:」（`docs/research/switch-identification.md:682` 就躺着一句），挂单 `Q1163`。

**漏数了会不会被发现：** 这一条不是「扫到什么算什么」——`Kind::ALL` 是那四样的**唯一**一处列举，
四样里**任何一样一处标记都没有就当场红**（`Error::Unwatched`），所以「新加一样该被数的东西
而没人给它加标记」这一档**会红**。另外三档也会红：标记里写了个不认识的名字、某张票没有行首
锚定的 `Status:` 行（那张票数不进去）、`-- --list` 的输出格式变了（逐条数出来的与每个测试
目标自报的总数对不上）。**唯一逮不住的**是「已经有标记的那个数，被人在别处**不带标记**地又
抄了一份」——限度写在 `xtask/src/numbers.rs` 模块文档「它拦不住什么」一节，挂单 `Q1164`。

**旧数错得有多厉害——这是「为什么要一条命令来写」最硬的论据：**

| 那一样 | README 上手抄着的 | 这一趟数出来的 | 差 |
|---|---|---|---|
| 测试条数 | 1,815 | **2,607** | **＋792（错了快一半）** |
| 测试目标数 | 70 | **86** | ＋16 |
| 票数 | 88/90（「前六条队列」）＋ 另记 59 张 | **148/152**（全仓） | 分法本身作废 |
| ADR 份数 | 24 | 24 | 0（这一样碰巧没漂） |

手抄的那两个是 2026-09-09 量在 `main` `a142612` 上的，**当天是对的**——README 上那句
「这个数会随票涨，以门禁自己的输出为准」也写着。十三天、四十来张票之后它错了 792 条。
**光靠免责声明不管用**，这就是那句话的证据。

**新加那一步贵不贵：热缓存下 2.8–3.4 秒**（连续三趟 5.3s／2.8s／3.4s，第一趟含 xtask 自己
那一次编译；门禁里的实测见下面「门禁」一段）。它**不重编、不跑测试**，只把 `test` 那一步
已经编好的 86 个测试二进制各起一次、把测试名字逐条印一遍。整棵冷编＋`--list`＋`--write` 一趟
2 分 51 秒，那趟编译的账本来就欠着。
