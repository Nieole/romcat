## 它建什么

`.scratch/rom-metadata-automation/deferred.md` 归档那天冻结了 75 条 `open`。逐条核过：
**作废 5 ／ 仍然成立 68 ／ 要真凭据才判得了 2**。裁定（2026-09-09）是**只过筛「有代码在催」
的那些**——纯方向题（第六个 DAT 源、第二家在线源、ZSO 壳子、拼音排序…）继续冻着，
那种没有东西在催，拍早了也是猜。

再核一遍，**68 条里有 11 条有代码在催（16%）**（其中 `D104` 已于当天做掉，剩 10 条）。它们不是十一件散事，是**同一个病的十一处**：
这个仓库在自相矛盾。三档：

- **档 1 —— 同一件事两处判据不同**，两处都活着（7 条）
- **档 2 —— 文档／词表／ADR 逐字说了一件事，代码做的是另一件**（4 条）
- **档 3 —— 一条设计前提在漏气**：当初写明「因为 X 所以这样便宜」，而 X 今天不完全成立（2 条，其中 `D64` 兼档 1）

判据严格是刻意的：**两侧都要给得出文件行号，缺一侧不收。**

## 裁定（2026-09-10，`/grill-with-docs` 两轮十二问）

**十件全部有裁定，三条规矩已落笔。** 规矩先说，因为四件的形状是从规矩推出来的：

| 规矩 | 落在哪 | 一句话 |
|---|---|---|
| **一个领域判断只有一处实现** | **ADR-0024（新）** | 答案与「在哪一层问」无关的问题就是领域判断，只许有一处实现。⚠️ **判断只有一处 ≠ 结论只有一处**——为性能物化一份结果是允许的，被禁的是第二次**判断** |
| **文档与代码互顶时，文档是决定** | `docs/agents/domain.md` | 但**「跟着改」不等于「照着实现」**：顶不动就改文档本身。通则管的是「不许放着两句互相顶的话」 |
| **不可再生的东西不住在中立库里** | **ADR-0001 修订** | 「整份可再生」是删库重扫那条便宜路的全部前提，已经免过五次迁移代码的账 |

### 逐件

| `Dn` | 裁定 |
|---|---|
| `D66` | **判断提成核心库一处，收「这份内容在库里的键」**——变体级调用方传变体键、内容级传成员键（`member_key` / `inner` 本来就在 `Candidate` 上，现成先例是那个用 `member != main_key` 判「是不是主文件」的排序函数）。**并且剥掉根名**：眼下根名那一段参与判断，一个真叫 `BIOS` 的根会让它底下所有东西被判成非游戏资产——那是缺陷不是特性 |
| `D142` | **把「这是不是补丁」提成核心库一处，两种依据都喂给它。** 实情比挂账写的重：有**两个独立的补丁判断**——一个按扩展名与名字里的词（`ips`/`ups`/`bps`…、「补丁」/`patch`），一个按 **TitleID 低 12 位**（`0x800`）；**只有前者到得了导出那道闸**，后者的唯一消费者是报告里一个 `GROUP BY` 计数。于是一份 `xxx[v1.0.2].nsp` **永远走不到那道闸**。按 ADR-0024 推论 2：输入由领域定，文件名与 TitleID **都是依据**，不是两个判断 |
| `D123` | **物化，落在识别结论那张表上**，刮削读那一列。**不回写 `variant.platform`**——那一列的语义是「目录声明的」，改它会让「平台冲突」那张报表失去对照物。这是 ADR-0024 推论 3 的头一个用例：物化结论允许，第二次判断不允许 |
| `D64` | **给导出一个开关，默认不铺媒体。** ⚠️ **两条路都被实测否掉了**：指向媒体池**跨不过适配器**（Pegasus 是内容寻址、路径就是哈希，ES-DE 镜像 ROM 相对路径、文件名是 ROM 名——池按哈希存，ES-DE 结构上找不到）；无条件铺一份则要**跨盘拷贝**（同步那套是硬链接，而硬链接跨不了文件系统，媒体池在工作目录、主库在那块外置盘上）。开关把「能不能做」与「这一趟要不要做」分开：能力补上，代价由人当场选，**默认不铺所以今天的行为一个字不变** |
| `D129` | **状态在全部候选都进来之后再定**（一次判断，一个候选集合）。眼下状态在模型候选 `extend` 进来**之前**就定死了，于是同一个候选集合一半算数一半不算——一个只有模型候选的变体，库里记的是「它一条候选都没有」，而词表**无判据**那一条逐字写着那是「一个字都没说」。**它说了，只是说的人是模型。** 改后它落进「有候选但没被自动通过」那一档。⚠️ **票面要写明**：这一改会让历史库的状态计数跳一次（重跑一趟识别就对上），不升结构版本 |
| `D128` | **标题队列也收中置信**，与识别那一侧同一判据（没人裁过就进队列）。否掉「让模糊匹配落低置信」：那是把**置信度这个描述性的量**当成「我希望它进哪个队列」的控制开关 |
| `D76` | **报告跟计划器**（目标现占 ＋ 净变化）。报告那个数存在的全部理由是让人在**按下之前**知道装不装得下，而真正会发生的是计划器算的那件事——报告答的是一个更好听、但不成立的问题 |
| `D97` | **只搬「成型的人工纠正」**，照沉淀库那一档办（单独一份文件、顺序迁移、永不要求删库）——它与**裁决**同类，是人一条条看出来的判断。子库的定义与**清单**、导入的前端快照**留在中立库并接受重扫会丢**，但**删库那句话要逐项说清会丢什么**。详见 ADR-0001 修订 |
| `D72` | **把 `标签` 从词表那半句删掉**（已改）——「汉化」本仓已有自己的表达（中文标记那一族），再造一个标签维是把同一件事说两遍。顺带给 `评分` 补了一句「立着，眼下没有源」：原先那一句话里混着两种不同的假 |
| `D37` | **一句话的事，已改**：`docs/platforms.md` 补上「**入库不等于进识别管线**」并指向 ADR-0011。核过了——两句说的是**不同阶段**（扫描入库 vs 识别管线），都成立，只是并排读像在打架。不改代码、不改 ADR |
