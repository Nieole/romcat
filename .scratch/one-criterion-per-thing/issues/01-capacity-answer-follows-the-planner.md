# 01 — 「装得下吗」以计划器为准

**What to build:** 维护者在**子库**屏上看见的「装得下吗」，与他真按下去同步时算的是**同一件事**
——目标上**已经占着的** ＋ 这一趟的**净变化**。它说装得下，就是真装得下；不会跑到一半才发现盘满了。

收挂账 `D76`：容量账把清单之外的占用也算进去（两处口径不同）。

**Blocked by:** 无 —— 可立即开工

**Status:** done

而真正会发生的是计划器算的那件事——报告答的是一个更好听、但不成立的问题。
