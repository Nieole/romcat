# 07 — 成型的人工纠正搬进沉淀库

**What to build:** 维护者哪天撞上结构版本变了、按提示删库重扫，**他一条条人工纠正出来的成型
还在**。而且删库那句提示会**逐项说清还会丢什么**，他按下去之前知道代价。

收挂账 `D97`：中立库里还剩几样不完全可再生的东西。

**Blocked by:** 无 —— 可立即开工

**Status:** ready-for-agent

⚠️ **搬进沉淀库、单开一张表**，不另开第三份库文件（ADR-0001 修订）。进了沉淀库就白拿那一档的
两条保证：**走顺序迁移、永不要求删库**。中立库那张表**删掉**，读它的地方改成读沉淀库。

⚠️ **默认不随沉淀库导出。** 「它只对本机成立、而沉淀库可导出分享」不构成反对——
**那个先例已经有了**：**路径锚**那些行就住在沉淀库里、默认不导出。人工纠正走同一条。

⚠️ **另两样不搬**：**子库**的定义与**清单**、导入的前端快照留在中立库并接受重扫会丢
（它们重建得回来）——但**删库那句提示要把这两样逐项说出来**。

⚠️ 现成样板：成型那份测试里已经有一条验「人工纠正熬得过**重扫**」的，新那条是它的另一半
（**删库**重扫）。

- [ ] 人工纠正**熬得过删库重扫**（删掉中立库文件、重扫一遍，它还在）
- [ ] 它默认**不出现在**沉淀库的导出里
- [ ] 中立库里那张表没有了，读它的地方全部改完
- [ ] 删库重扫那句提示**逐项**说清会丢什么（子库的定义与清单、导入的前端快照）
- [ ] 沉淀库那一侧走的是顺序迁移，旧的沉淀库文件打开就能用、不要求删
