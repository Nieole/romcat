# 02 — 标题队列也收中置信的中文名

**What to build:** 一条模糊匹配来的中文名落**中置信**时，它照旧进**标题集合**那条待裁的队列——
维护者看得见它、裁得了它。此前它一进库就退出了视线，可能直接当上**显示标题**，而他一眼都没看过。

收挂账 `D128`：模糊匹配来的中文名算中置信，退出了标题队列。

**Blocked by:** 无 —— 可立即开工

**Status:** ready-for-agent

⚠️ **判据改成与识别那一侧同一条：没人裁过就进队列，不看置信度。**
**否掉「让模糊匹配落低置信」那条路**——那是把**置信度这个描述性的量**当成「我希望它进哪个队列」
的控制开关，同一个病换个地方长。

- [ ] 一条中置信的中文名进得了标题队列
- [ ] 已经被人裁过的那些**不再**进队列（判据是「裁没裁过」，不是置信度）
- [ ] 低置信那些照旧进队列，行为不变
- [ ] 置信度这个值本身**一个字没改**（没有为了让它进队列而调档）
