# 06 — 落点闸：可注入的目标侧接缝

**What to build:** 「落点被占就不写」这道闸，在**大小写不敏感**的目标（FAT32 / exFAT 的卡）
上有测试真的钉着——而不是靠一句「敏感那边挡得住，不敏感那边只会更容易挡住」的推理。

这条挂了两轮，两轮的理由都一样：同步执行层直接吃真实文件系统，**没有能塞进一个假文件
系统的地方**，而开发机（ext4）造不出一个大小写不敏感的挂载点。（挂单 `Q135`）

**这是本轮唯一新增的测试接缝。**

## 硬约束

- **主库只读**（ADR-0004）。测试一律用本地 fixture 目录模拟目标设备，绝不碰任何真实设备或 SD 卡。
- **路径键一律 NFC 归一**，从磁盘读时用原始形态（ADR-0020）。这条被违反过四次——加接缝时最容易在「假文件系统里存的是哪种形态」上再违反一次。
