## 收尾

**并出来的那份夹具长什么样**（票 `17` 接的就是它）。入口一个：

```rust
shared::小库(&[(平台, 名字, shared::档), …], workspace) -> App
```

一行 `(平台, 名字, 档)` 造一个变体，键是 `主库/<平台>/<名字>`。`档` 四个值，
差别只在**结论表**那一行上：

| `档` | 结论表那一行 | 屏上认成 |
|---|---|---|
| `档::命中` | `Matched` + 一条高置信、已采纳的候选 | **命中**（高置信） |
| `档::待裁决` | `Unmatched` + 一条低置信、没采纳的候选 | 进得了**待确认队列** |
| `档::没有候选` | `Unmatched` + 一条候选都没有 | **没有候选** |
| `档::还没识别` | **一行都不写** | **还没识别** |

调它能调的：**要几个变体、各落哪一档、摆在哪几个平台上、工作目录是哪个**。
`shared::变体` 与 `shared::候选` 也是公开的，要单造一格时直接拿。
**规模只在那个切片的长度上**——票 `17` 要把它推到真库量级，改的是那一处切片，
不用碰两份测试里的任何一条断言。

**这一趟记了 `Q344`–`Q350`**（`.scratch/PARKING-LOT.md` 条目区）：
`Q344` 并夹具时统一的那两格、`Q345` 「翻行看得出来的延迟」这道门留给票 `17`

`Q349` 门禁里还剩第二张挂钟彩票（`sublibrary.rs:226`）、

### Q346 — 共用模块整份压掉了 `dead_code`，不是逐项挂

- **来自：** 票 `parking-3/16`
- **类别：** 规格没说
- **在哪：** `crates/gui/tests/shared/mod.rs` 顶上那句 `#![allow(dead_code)]`
- **为什么没停线：** 压掉的是一条 warn 级 lint；`clippy --workspace --all-targets
  --all-features` 照旧零告警，退出码一次都没变过。
- **这张票实际做了什么：** `tests/shared/mod.rs` **整份**编进每一个 `mod shared;` 它的测试
  二进制（眼下四个：`queue` `browse` `layout` `sublibrary`），而搬进来的那几个搭子只有
  `queue` 与 `browse` 用得上——在 `layout` 与 `sublibrary` 那两个二进制里它们就是死代码。
  加了模块级 `#![allow(dead_code)]`，并在注释里写清这条告警在这儿说的不是「这段代码没人用」
  而是「这个二进制没用它」。另一条路站得住：逐项挂 `#[allow(dead_code)]`，将来真有一样
  彻底没人用时还看得出来。没走它，是因为搭子是成套的（`档` / `变体` / `候选` / `小库`
  四样连着走），逐项挂等于在每一样头上重复同一句话；而这个模块本来就是「谁用得上谁拿」
  的地方。翻案的代价是把一行 `#![allow]` 拆成几条 `#[allow]`，全在这张票之内。
- **谁来裁：** 收尾
- **状态：** settled —— 第三轮收口 2026-09-08，走 **A（已经做完，收口只是销号）**
- **收尾裁决（第三轮收口，2026-09-08）：** **A** —— 共用模块整份压 `dead_code` 并在注释里写清这条告警在这儿说的不是「这段代码没人用」而是「这个二进制没用它」。理由：搭子是成套的，逐项挂等于在每一样头上重复同一句话。`clippy --all-targets --all-features` 照旧零告警。
