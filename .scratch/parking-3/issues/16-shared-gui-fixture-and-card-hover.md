# 16 — 界面测试夹具并成一份 + 批次卡片补悬停

**What to build:** 两件小事，一件是给后面几张票铺路的 **prefactor**：

1. **两份界面测试共用同一份小库夹具。** 现在队列与浏览那两份测试各搭了一份约 70 行、
   几乎逐字相同的夹具（同一句加根、同一个变体搭子、同一批识别字段，连注释都一样），
   而共用模块就是为这个建的。改一处要记得另一处也改。（挂单 `Q192`）
2. **屏上那张批次卡片补一句「命令行上是什么」的悬停。** 三个轴的输入框都有，卡片没有——
   维护者从界面上挑好的那一批，得回命令行再列一次才拿得到那串字。（挂单 `Q177`）

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 那三个搭子（造变体、造候选、搭一份小库）搬进共用模块，两份测试一起换过去。
- [ ] 换过去之后两份测试**断言一条不改、结果一条不变**——这是纯粹的去重，不是重写。
- [ ] 批次卡片上挂一句悬停，印出这一批在命令行上是什么。折算那一对核心库里已经备好了。
- [ ] 有一条界面测试断那句悬停摆得出来。
- [ ] 挂单 `Q192` `Q177` 标 `settled` 并分别迁回票 `gui-redesign/17` 与 `queue-followups/08`。

## 为什么排在票 17 前面

票 `17` 要把合成数据换成真库的形状，那会动一批断言基线。夹具先并成一份，`17` 就只改一处。
