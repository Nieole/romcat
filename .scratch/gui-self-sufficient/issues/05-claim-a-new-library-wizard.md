# 05 — 开场：认领一个新主库

**What to build:** 在开场上认领一个新**主库**，全程不必开终端。一条龙向导三步：起主库名 → 选第一个**根** → 开扫。走完直接进主窗口，扫描已经排在**任务台**上跑着，你能立刻看进度、也能按停。

**名字撞了在第一步就拦下**——工作目录里已经有同名的库时当场说，而不是等你选完目录、按下开始才发现。

**领域判断一条都不许长在向导里**：加一个根要拦的三种情况（根名重复、与已有的根套在一起、圈进工作目录）全部调核心库现有的加根入口。向导重画 UI，但判断必须是同一个函数——两套判断只会分叉出两套行为（ADR-0005 的红线）。

**晚落盘**：起名与选根两步只在内存里攒，按下"开始扫描"才真的开中立库。中途关窗，磁盘上什么都不留——一份零根的空库对人没有用处，却会永久占着开场的一行。

**向导摆成什么形状、入口怎么进：**

入口是**开场抬头那一行**上那颗「认领新主库」（`opening::Screen::workspace_ui`，票 `03`
在代码里点名留的那个位子），紧挨着「工作目录 <路径>」——**认领进哪儿**正是这一下最要紧的
事。按下去，开场那张库表让位给向导（一条龙走到一半还摆着一排现成的库，只会让人在
「认领一个新的」与「开那一份」之间来回犹豫），换工作目录那一行同时收起来（向导第一步
查的重名是在**这个**目录里查的）。

向导本身是**两块界面 + 一颗按钮**：第一步起主库名（「下一步」当场查重名），第二步选第一个
根的目录与根名（两个框的提示字与库屏加根**共用同一对常量**），第三步「开扫」就是第二步上
那颗「开始扫描」——中间没有任何新信息，单摆一屏只让人多按一下确认（挂单 `Q406`）。
两步上都有「算了」，第二步还有「上一步」。走完交出一份刚开出来的**现场**加一个还没加上的
第一个根，由 `Program::ui` 换成主窗口（走 `opened_with`，那一份于是被记住）之后交给
`App::claim_first_root`：加根、排扫描、换到任务屏。

**晚落盘那条测试怎么验的：**

`gui/tests/program.rs::向导走到第二步就放弃时工作目录里一个文件都不多`。判据不是「库文件
在不在」，是**整个工作目录递归数一遍**（辅助函数 `底下有什么`，连子目录一起收，因为中立库
落在 `<工作目录>/catalog/` 底下，只数顶层的话建出来也看不见）。开场之前先断言那个工作目录
**本来就是空的**，然后两条路各走一趟：

1. **中途关窗**——点「认领新主库」、打上主库名、点「下一步」进第二步、把根目录与根名两个框
   都填好，**就是不按「开始扫描」**，直接把 `Program` 扔掉。再数一遍：仍旧是空的。
2. **按「算了」**——同一条路走到第二步，按下去回到那张表（屏上重新出现「还没有库，认领一个
   主库开始」）。再数一遍：仍旧是空的。

末了还有第三句：**再走一遍向导，那个主库名还空着**（「下一步」照旧进得到第二步）。这一句
钉的是「放弃过一趟之后没有留下任何痕迹」——留下一份零根空库的话，人重走一遍会在第一步被
自己刚才那一趟拦住，而且看不出为什么。

另有两条从背面钉着同一件事：`向导里选的根圈进工作目录时被拦下说的是加根那一处的原话` 与
`向导里根名不能用时说的也是加根那一处的原话`，都在**被拦下之后**比对整个工作目录与动手前
一模一样——**判断走在建库之前**（`Wizard::claim` 先在一份 `Catalog::open_in_memory` 的库上
把加根走一遍），不是建完再回头拦。落盘那一步自己也留了退路：`Catalog::open_named` 成功、
`Site::open_file` 却失败时（**沉淀库**是工作目录里共用的那一份，它可能开不动），把刚建出来
的那一份连 `-wal`／`-shm` 一起收掉。

**交给下游的三样：**

- **共用的加根接缝**：`romcat_gui::roots::add_root_from_fields(catalog, workspace, path, name)
  -> Result<LibraryRoot, String>`。「两个框 → 一次 `roots::add_root` 调用」的全部折算在它
  里头（目录空着、那不是目录、名字不填时按目录自己的名字取），拦不拦得住与那句措辞仍旧全在
  `romcat_core::catalog::roots::add_root`。库屏 `Screen::add_root` 与向导都调它——**谁再加
  一条加根的路都该调它**。`Screen::add_root` 顺带改成交出**加上去的那个根名**
  （`Option<String>`），排扫描要的正是这个名字。
- **向导那一段的形状**：`romcat_gui::claim`——`Wizard::new(workspace)` /
  `Wizard::ui(ui) -> Outcome`（`Going` / `Dropped` / `Done(Box<Claimed>)`）。
  `opening::Chosen` 多了一格 `first_root: Option<claim::FirstRoot>`：**挑中一份现成的库时
  它是 `None`**，刚认领出来的那一份才欠着这一下。
- **进主窗口之后那一下**：`App::claim_first_root(&claim::FirstRoot)`——加根、排扫描、换到
  任务屏。**它不是第二条加根的路**（验收第 8 条），只在向导走完那一下走一趟。
