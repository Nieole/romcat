# 04 — 开场：记住上次开的那份，下次直接进

**What to build:** 开场不该每天挡在你前面。记住上次开的那份中立库，下次启动直接进主窗口；**开场只在两种时候出现**——记的那份打不开了（挪走、删了、结构版本对不上），或你主动要换库。主窗口里要有一条回开场的路。

记的是**那份中立库的完整路径**，不是工作目录：从"工作目录 / 中立库目录 / 某某文件"这个形状反推工作目录的办法界面里已经有了，记一条路径两样都拿得到，也不会两样对不上。

这份记忆**不属于任何工作目录**：所有偏好都住在工作目录里（版式偏好就是），而"工作目录是哪个"没法住在工作目录里。它是程序级配置，位置固定取默认工作目录那条链的结果——于是在 Windows 上它与默认工作目录落在同一个地方，**同一个目录下住着两种东西**。这不会出错，但注释里要写明白，否则下一个人会绊一下。

**交给下游的三样：**

- **那份程序级配置在哪、什么格式**（票 `05` 建完库之后要把新那份记进去）：
  `romcat_gui::recent::Recent`——`Recent::here()` 折出
  `<romcat_core::workspace::default_dir()>/last-catalog.txt`（Linux 上就是
  `~/.local/share/romcat/last-catalog.txt`，Windows 上是 `%APPDATA%\romcat\last-catalog.txt`
  ——**那儿恰好也是默认工作目录**）。纯文本：几行 `#` 注释 ＋ 一行
  `catalog = <中立库的完整路径>`。写：`Recent::remember(&Path)`（**不报错**，已经记着它了
  就一个字节都不写）；读：`Recent::read() -> Option<PathBuf>`（**没记过、读不动、读不懂
  一律是 `None`**，那时就走开场）。`Recent::at(PathBuf)` 把它记到别处——**测试一律用它**，
  真的那一处不许碰。

  `Stage::Opening(opening::Screen::new(眼下这个工作目录))`，那份记忆原样带着走。
  `App` 这一层**不换库**：它拿的是一份已经开好的现场，换库整个归 `Program`。
