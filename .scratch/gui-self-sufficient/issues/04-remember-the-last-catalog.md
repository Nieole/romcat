# 04 — 开场：记住上次开的那份，下次直接进

**What to build:** 开场不该每天挡在你前面。记住上次开的那份中立库，下次启动直接进主窗口；**开场只在两种时候出现**——记的那份打不开了（挪走、删了、结构版本对不上），或你主动要换库。主窗口里要有一条回开场的路。

记的是**那份中立库的完整路径**，不是工作目录：从"工作目录 / 中立库目录 / 某某文件"这个形状反推工作目录的办法界面里已经有了，记一条路径两样都拿得到，也不会两样对不上。

这份记忆**不属于任何工作目录**：所有偏好都住在工作目录里（版式偏好就是），而"工作目录是哪个"没法住在工作目录里。它是程序级配置，位置固定取默认工作目录那条链的结果——于是在 Windows 上它与默认工作目录落在同一个地方，**同一个目录下住着两种东西**。这不会出错，但注释里要写明白，否则下一个人会绊一下。
