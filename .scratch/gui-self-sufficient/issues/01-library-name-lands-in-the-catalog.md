# 01 — 主库的名字落进中立库

**What to build:** 你给主库起的那个名字，现在只活在你敲过的那行命令里——中立库的文件名是"可读的那一段 + 哈希"，可读那段滤过非法字符、截断到 24 个字符，哈希那半段不可逆，忘了就再也拿不回来。这一张让名字有个落点：建库时写进中立库的元数据表一行，读得回来。**可演示处在命令行**：对着现有的库跑一次报告，看见的是你起的那个名字，而不是一串带哈希后缀的文件名。

元数据表是键值表，加一个键是**纯加**——按仓库既定的判据（改了已有表的列或含义才升结构版本），这不构成升版。旧库拿新程序打开照样能用，读不到那行就退回从文件名截取。

**Blocked by:** None — can start immediately
