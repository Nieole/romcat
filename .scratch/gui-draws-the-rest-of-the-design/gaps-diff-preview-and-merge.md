## 六、样式岔路口汇总（编排者逐条问拿主意的人）

**F-1 · 摊开那张卡的底排摆哪儿、「我看过删除清单」放哪儿**

**F-2 · 「净变化…｜排它用了 N ms」那一行**

选项：A 净变化与「同步完之后目标上占 X（眼下 Y）」并进上面那行小字（help 色 12 号），去掉「排它用了 N ms」与「｜」；B 整行去掉；C 留现状。
**推荐 A**。

**F-3 · 计划里那几步的动作词：「复制」还是「新增 / 更新 / 删除」**
稿列表写「复制」，大数字写「新增」；现在一律「新增 / 更新 / 删除」（`Act::label`，命令行同词）。
选项：A 留「新增 / 更新 / 删除」；B 照稿「复制」（更新那一档也叫复制？稿没画更新）。
**推荐 A**：与大数字、词表**差量预览**条同词，「更新」那一档稿上没有、不另造。

**F-4 · 计划那一段的抬头「这一趟要动的 N 步（先删后传）」与「元数据 / ROM / 媒体」那一列**
稿两样都没有。

**推荐 A**：路径本身说得清是不是元数据与媒体，卡头标签已经写着「待同步 N 个文件」。

**F-5 · 异常各栏说明句与「不收的字符」那条劝告：照稿短句还是留现在的长句**
（ADR 编号无论如何都去掉，那是 D-14。）稿：「…可能被手动删除了。默认不补回。」「…可能被其他工具改过。不会覆盖，也不会删除。」「…不是 romcat 放的文件（清单外文件），不会覆盖。」「Windows 与 exFAT 都不收 \ / : * ? " < > \|。在主库里改名后重新扫描即可。」现在的更长、带「多半是你自己拷进去的」「要补得你明说」这类话；命令行与界面同一份（核心 `SurpriseKind::refusal`、`RejectReason::advice`）。「元数据读不到」稿没画，只能留现在那句（去编号）。
选项：A 照稿短句（命令行跟着变短；「romcat」换成「工具」）；B 留长句只去编号。
**推荐 A**：稿那几句已经说清「工具不会做什么」，这正是词表**异常**条要的；不收的字符那句把具体字符列出来（取 `Filesystem::forbidden`）比「改掉那个名字」好用。
