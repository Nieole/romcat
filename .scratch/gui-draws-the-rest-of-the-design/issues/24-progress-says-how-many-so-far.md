# 24: 长活的进度照稿说「已经走了多少」：核心进度带件数与单位

**What to build:** 稿上扫描正在跑时写「已扫描 95,133 个条目 · 并发 4（根据硬盘速度自动设定）」，数一直在涨。今天核心任务台那份进度只报得出第几步/共几步、这一步里第几件/共几件：
- 总数说不出来时，`Progress::render` 不印已经走过的件数；
- 进度没有单位。

结果是真库上遍历要半小时上下，库屏扫描那一行（票 11）与任务屏那张卡一直停在「25% · 2/4 遍历」同一句，名为实时进度，看不出在动。

让核心任务台的进度带上**已经走过的件数**与**单位**（条目 / 文件 / 变体 / 请求……，由排活入口交，同副标题槽那样可选）：
- 总数说得出时照旧带百分比；
- 说不出时只说走过的件数，写成「已扫描 N 个条目」这一类。

库屏工序段那一行与任务屏那张卡读同一处，界面不自己拼。稿上「并发 4（根据硬盘速度自动设定）」那半句，核心今天答得出就照稿接，答不出就列选择题交拿主意的人。

来源：拿主意的人 2026-10-05 在票 11 的人的关上裁：票 11 照旧写「25% · 2/4 遍历」，核心进度带件数与单位另开这一张。
