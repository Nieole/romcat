# 22: 表格与卡片墙同一个动作说同一件事：空格勾选、双击开详情页、一行一个 Tab 站

**What to build:** 稿上那句是「交互与表格一致：点击卡片在右侧显示详情，勾选用于批量操作……键盘可用 Tab 移动、Enter 查看、空格勾选」（`prototype.html` 约 1334 行）。快捷键表「浏览」那一组也是这么写的：「Enter 打开作品详情」「空格 勾选 / 取消勾选」（约 3267 行）。票 20 做完之后还剩三处对不上：

- **表格一行拿着焦点时按空格**，照旧等于点一下那一行（高亮、开侧边详情），不是勾选（挂单 `Q1787`）。照稿与卡片墙改成勾选 / 取消勾选那一行。
- **卡片墙上双击一张卡**，开的是侧边详情（挂单 `Q1788`）。照稿与表格那一路，改成开作品详情页、停在概览。
- **表格每一行有七个 Tab 站**（每一格一个），只有行首那一格画焦点圈，其余六下屏上看不出焦点在哪（挂单 `Q1789`）。照稿收拾：要么每一行只留一个 Tab 站，要么哪一格拿着焦点都给整行描圈；稿上怎么画就怎么做，稿没画的列成选择题交拿主意的人。表头那几格同理。

认键与问门照票 20 立的那一处走（`keys::press` → `keys::allowed`），不另起一份。

来源：拿主意的人 2026-10-04 在票 20 回报之后裁（挂单 `Q1787`、`Q1788`、`Q1789`）：开一张小票，三处都照稿统一。

收挂单 `Q1787`：表格行上空格 = 勾选 / 取消勾选。
收挂单 `Q1788`：卡片墙上双击 = 开作品详情页。
收挂单 `Q1789`：表格一行一个看得见的 Tab 站（或整行描圈），表头同理。

规格：`../spec.md`；稿 `../../gui-looks-like-the-design/prototype.html`（卡片墙与表格的键盘、快捷键表）。
