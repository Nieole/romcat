# 02: 任务带副标题（八种长活照稿填）

**What to build:** 任务台与任务屏上每一趟长活名字底下有一行副标题，说清它在做什么（例如差量预览那一趟：「只读取库和设备上的目录，不写入文件」；扫描那一趟：扫的是哪个根）。
核心库给任务加一个**可选副标题槽**，排活的各个入口照稿各交一句。收口时 `Q835` 裁的「正在跑那张卡先不画副信息」随之作废——那一行就是这个槽。
