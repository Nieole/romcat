# 17: 刮削弹层照稿：标头、三栏、预估块、提示框

**What to build:** 「刮削元数据」那一层弹层照稿画（票 13 做过的「采法两行」「排上就关」之外的其余部分）：
- **标头**：标题「刮削元数据」；说明那句带作品数与变体数，范围分三种说（拿主意的人 2026-10-02 裁 `F-1`）——全选时照稿「应用于当前筛选结果：N 个作品（M 个变体）。如需调整范围，请修改筛选条件。」；部分勾选「应用于勾选的 N 个作品（M 个变体）。如需调整范围，请修改勾选。」；从详情页「刮削此作品」进来「应用于「作品名」：M 个变体。」（`F-15`：详情页照旧摊开这一层，不直接排）。
- **三栏**：小标题走 `look::section`、列距照稿；第三栏叫「采法」（`F-2`）。字段那一栏照 `.opt` 两行；「开发商 / 发行商」照稿并成一格，拨它同时拨两个字段，只在界面层折（`F-3`）；「标题与汉化组永远采」那句不再常驻，挪进「字段」小标题的悬停（`F-4`）。
- **数据源那一栏**（`F-5`）：照稿逐行画「中文离线源」「DAT」「本地媒体」与 ScreenScraper，各带一行小字（「本地 · 不消耗配额」这类）；本地三行勾着、画灰按不动（核心不加逐源开关）；「本地媒体」跟「媒体」那一格走（不收媒体时不勾，小字「勾上『媒体』才参加」）；没取回的那一行小字换核心库给的状态词（`core-answers-once/10`）；源名与优先级表、报告是同一个名字。
- **勾联网源那一下**（`F-6`）：照稿勾上即生效，**去掉今天那一层「我知道，勾上」**；预估框换警示样并常驻、右侧写稿上那句短话（「将消耗 ScreenScraper 配额。配额按账号和 IP 计算，超出可能导致封禁。」）；原来那句长警告挂在 ScreenScraper 那一行的悬停上（设置屏照旧用它）。这一条**翻掉票 gr-10 当年的那一条验收**，拿主意的人点了头；ADR-0007 要的限流与硬停在核心里，不靠这一层。
- **没有 ScreenScraper 账号时**（`F-7`）：那一行照样勾得上，小字「没有账号——在设置屏填好之前，开始时会拒」；按「开始刮削」拒下的那句指向设置屏（环境变量那句留在悬停）。「有没有账号」问 `verdict-store-and-sync/15` 立的那一处。
- **预估那一块**：照稿 `.est` 一框三格——网络请求 / 预计耗时 / 读取硬盘——加右侧一句：
  - 联网又收媒体时请求数是下界：数后加「+」，右侧补「另加下载图片的请求，有几份要查过才知道」（`F-8`）。
  - 想问的超过这一趟自设上限时，写这一趟真会发的数，右侧说「这一批想问 N 条，这一趟到 200 就停，剩下的下一趟再来」（`F-9`）。
  - 不到 1 秒写「不到 1 秒」，其余照核心粗估；这一档加在核心 `human_duration` 旁边（`F-10`）。
  - 读取硬盘那一格：核心补这个数——这一批收媒体首趟要从主库读多少字节（`local::index` 那份归属表按范围求一次和、已入池的不算；只依赖范围，摊开时算一次缓存住，拨旋钮不重算），耗时也加上读盘那段。**先在真库上量一次那一问多久**，超过一两百毫秒就退成「不收媒体写 0 B、收媒体写『—』，右侧说首趟要把图从主库读一遍、读多少要读过才知道」，并记挂单（`F-11`，差距 `C-1`）。
  - 勾了联网、却一个可查的条目都没有时，不警示，右侧说「这一批没有可查的条目（只对已确认的条目发请求），不会产生网络请求」（`F-12`）。
- **底部提示框**：「有值了但我想换一个」那句与「调整优先级…」并进底部 `.note` 提示框，照稿那两句。
- **按不动的几态**（`F-13`）：理由常驻在页脚左边（`Dialog::footer_note`），按钮同时画灰；`start()` 自己拒「那本账算不出来」这一态，拒的与屏上常驻的是同一句（ADR-0005 再修订两条；今天 `start()` 只拦「台上有一趟」与「范围空」，绕过界面能在零估算下开跑——差距 `S-20`）。票 13 之后弹层排上就关，「开始刮削」的悬停字跟着改成实话。
- **页脚**：「取消」ghost，去掉分隔线；弹层宽留 720（`F-14`）。
