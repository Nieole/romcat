# 16: 合并向导与「移出此作品」照稿

**What to build:** 合并向导三步与「移出此作品」那一层照稿画（票 03 补的封面缩略图、副标题、`.keepb` 之外的其余部分）：
- **第一步**：`.mwit` 整张卡是一颗按钮（点哪儿都换保留的那一个），悬停描边换 `line-2`，选中那张描边强调色 + 3 点 `accent-soft` 外圈；作品名 13 号（拉丁粗）；补「建议一并合并」那一段——参与的作品里有一个与库里别的作品是**疑似同一作品**、另一边还没在向导里时：小标题 + 一行「作品名 · 第一条理由 · 添加」（核心 `Suspicion::{touches,other_than,reasons}` 现成，理由逐字取它）；「添加其他作品」的搜索结果装进 `.srch` 框（最高 170 框里滚、行间分隔线、悬停底色），**整行按下去就添加**，平台用平台色标，名字粗；没搜时列 4 个。
- **第二步**：平台组照稿 `.vgrp`——头一排满宽 `panel-2` 底 + 下分隔线、平台色标 + **粗体全名**（`Platforms::full_name`；缺全名的平台退回代号，其余平台的全名归票 04）+「N 个变体」；一行变体照稿 `.vrow`——单行、整行竖直居中、行间分隔线；勾选框单独一列（名字那一格也接点击，靶子不变小）；名字粗、路径等宽单行省略；「来自「…」」那一列单行省略；置信度用 `look::chip`（浅底 + 圆点 + 词），不再是色条。
- **变体路径**：第二步与移出那一层都写「根名 · 相对路径」（`table::root_and_path`；拿主意的人 2026-10-01 裁 `F-8`）。
- **第三步**：冲突表收紧——每个选项用 gd-01 拆出来的单独圆点，不再一行一个带空说明的 `radio_option`，「合并后会发生什么」第一条不出折叠线；行间分隔线、表头下一条线，替掉斑马纹（今天斑马那一条右边还没铺满）；表头照稿 `.tbl th`（11.5 号 600 `ink-3`），不走小标题；标题那一行叫「显示标题」（词表**显示标题**，只改这一处称呼）；字段次序照稿：显示标题 / 简介 / 类型 / 开发商 / 发行商 / 年份；别人那一格「类型 · 作品名」作品名取 help 色、只隔一个「 · 」；「保留为别名」「自动归入」两格走 `look::checkbox_option`（说明缩进挂在名字底下，自动归入那格整格调淡）；自动归入那句尾巴「——再合一次就归进《X》了」删掉（`F-9` 只删这一处）。
- **「移出此作品」**：弹层宽 620（`Width::Standard`）；「移到」两档照稿 `.asmode`——每档一张卡（选中强调色描边 + 外圈），名字粗，输入框与说明缩进 28 挂在那一档底下；「移入另一个作品」的候选装进 `.srch` 框，每行圆点 + 平台色标 + 粗名 +「年份 · N 个变体」，选中那行 `accent-soft` 底，没搜时列 5 个、同平台的排前（走 `WorkQuery`，不另判）；首选变体那半句写**变体简称**（`Catalog::variant_short_names`），不写文件名；括号「（照…重选）」与撤销那条「，变体回到原来的作品。」留着（`F-9`）。
- **两层页脚「取消」**改 ghost 按钮（`Button::ghost` 现成）。

逐条差距与代码位置见 `../gaps-diff-preview-and-merge.md`：本票收 `M-01`…`M-20`，岔路口 `F-8` `F-9` 照文末「裁定」做。「由别处移入」那一档仍不做（票 03 / `Q1013`）。
