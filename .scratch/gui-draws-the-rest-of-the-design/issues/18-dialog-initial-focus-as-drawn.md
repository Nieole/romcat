# 18: 弹层起手焦点照稿

**What to build:** 弹层一打开，键盘焦点落在设计稿上那一处，而不是全仓那条「落在第一个能拿焦点的控件上」的老规矩。今天的后果：焦点圈落在头一颗单选或头一格标签上，那一枚没被选中时乍看像选中（合并向导第一步）、焦点圈挡住下划线标签（手动例外弹层）。
照稿：
- 合并向导第一步：焦点在**保留的那一张**卡上。
- 「移出此作品」：焦点在**名字框**里（「新建一个作品」那一档）。
- 手动例外弹层：焦点在**搜索框**里。
- 其余弹层逐个对稿：稿上起手焦点在哪就放哪；稿上看不出的，落在主按钮之外第一个**要人填写**的输入框；一个输入框都没有的弹层，起手不画焦点圈（键盘一按 Tab 才出现）。
起手焦点由共用弹层（`dialog.rs`）一处给出，各弹层只声明「起手给谁」，不各自抢焦点。

来源：拿主意的人 2026-10-02 在 gd-14（手动例外弹层，岔路口 6）与 gd-16（合并向导与移出，岔路口 3）的人的关上裁的：这两张票不动，另开这一张全仓一起照稿改。
