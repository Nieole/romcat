# 14: 差量预览照稿：账、计划里那几步、异常那一块

**What to build:** 子库屏上排过差量预览的那张卡，差量那一块照稿画：
- 五格大数字：正负号写 `+` / `−`（ASCII 加号、U+2212 减号），不再是全角「＋」「－」；字仍是等宽常规（拿主意的人 2026-10-01 裁 `F-10`）。
- 账底下那行「净变化…｜排它用了 N ms」并进上面那行弱色小字：净变化与「同步完之后目标上占 X（眼下 Y）」留，「排它用了 N ms」与「｜」去掉（`F-2`）。容量与差量账之间去掉那条横线。
- 计划里那几步：去掉抬头「这一趟要动的 N 步（先删后传）」与「元数据 / ROM / 媒体」那一列，「共 N 步，先删后传」并进框里末一行小字（`F-4`）；整张列表装进稿上 `.steplist` 那个框（描边、圆角、行间分隔线、最高 150、框里滚），不再「摆头 6 条 + 全部展开 / 收起来 + 可拖列宽的表」；动作词留「新增 / 更新 / 删除」（`F-3`），照稿粗、删除取 `lo` 色、新增取 `hi` 色；路径等宽、一行放不下省略号；转换那一步带「→ 转为 zip」（核心库 `Step::convert` 现成，措辞与命令行报告同一处）。
- 异常那一块：去掉「异常」那个小标题；外框照稿 `.anom`，头一排换成**下划线标签页**（选中 `ink` + 粗 + 强调色下划线，条数等宽小字跟在名字后）——作品详情页已有一套下划线标签（`browse/work.rs`），抽成共用件，手动例外弹层那一排同一写法跟着换；每一栏的条目装进 `.lst` 框（描边、圆角、行间分隔线、等宽），「另有 N 个」是框里末一行。
- 行尾：「选择集还要它 / 已经不要它了」留、弱字靠右；撞车每份的体积去掉（`F-6`）。
- 「放不进目标」的撞车：一处一个 `.lst` 框，头一行落点路径、右头一枚「撞车」标签；每份来源写「根名 · 相对路径」（`table::root_and_path` 现成），右头「排除这一份」。
- 「同步时补回这 N 个文件」那一格走 gd-01 立的 `look::checkbox_option`（说明小字缩进挂在名字底下）。
