# 02 — 能力档位说出 Pegasus 丢掉的换行与前导空白

**What to build:** 导出到 Pegasus 之前，**能力档位**就说得出这个格式会丢掉哪两样：简介里的**单个换行**折成空格（只有空行分隔的段落往返得回来），以及简介开头的**前导空白**（含全角空格）被掐掉。

中文离线源产出的简介两样都带——开头两个全角空格是那份数据源的常态。眼下导出再读回来，排版悄悄变了，而用户会以为是刮削出了问题。

**不改 Pegasus 的读写。** 这两样是这个格式自己的天花板：读那一侧把续行折成空格、只有 `.` 是段落分隔；前导空白与续行缩进在这个格式里长得一模一样，分不开。ADR-0003 定的能力档位本来就是"导出前就知道这个格式会丢掉什么"——这一票补的是**它说不说得出**。

**Blocked by:** 无 —— 可立即开工

**Status:** done
