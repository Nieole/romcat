# 05 — 开场那几行按上次扫描时刻倒排，没扫过的在最前

**What to build:** 维护者打开**开场**屏，**他刚在弄的那一份**排在最上面，而不是名字码位最小的
那一份。**从没扫过**的那些排在最前——那是「建出来了却没开工」的，最该被点进去。

收挂单 `Q389`：开场那些行按主库名的码位排，人看见「乙库」排在「甲库」前面。

**Blocked by:** 无 —— 可立即开工

**Status:** ready-for-agent

⚠️ 「上次扫描时刻」列举**本来就带着**（有现成测试钉着它盘没挂上也交得出），
这一件不需要新数据。

⚠️ **从没扫过的排最前**，不是最后：它是**未完成**的那一份，未完成的东西该看得见；
排最后会让它沉到底下，而那正是人最该点进去的一行。

⚠️ 否掉按拼音排——要一张汉字读音表，这个仓库一份都没有。
**「每次打开次序都一样」这条要求照旧要满足**（目录列出来的次序是文件系统给的，两次不保证一致）。

⚠️ 现成那条断言「按码位排」就写在列举那份测试里，跟着改。

- [ ] 两份库、一份刚扫过一份很久没扫，刚扫过的排在前面
- [ ] 一份**从没扫过**的排在最前
- [ ] 同一个工作目录列两次，次序**一样**
- [ ] 那条写着「按码位排」的现成断言跟着改完
