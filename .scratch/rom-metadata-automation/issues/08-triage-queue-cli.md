# 08 — 待确认队列与批量裁决（命令行）

**What to build:** 置信度不足的候选进入**待确认队列**，维护者能在命令行上列出队列、查看每条的依据、并按目录、按候选作品、按命名规律**批量裁决**。每条裁决沉淀进**沉淀库**，把文件哈希直接钉到发行版上——裁决一次，重装、换机、日后再次拷入同一文件时直接精确命中。

先做命令行版本，因为队列的逻辑在这里就能跑通并测试；界面是后面的一层壳。

**Blocked by:** 07

**Status:** ready-for-agent

- [ ] 队列能列出待裁决的变体及其全部候选与依据
- [ ] 支持按目录、按候选作品、按命名规律批量裁决
- [ ] 维护者能判定「都不对」并手工指定，候选集不构成天花板
- [ ] 裁决结果写入沉淀库，键为文件哈希
- [ ] 沉淀库能导出为可分享的格式
- [ ] 已沉淀的哈希在下次识别时直接命中，不再进队列
- [ ] 裁决时能补充汉化组与版本信息
