# 07 — CRC-32 精确识别

**What to build:** 识别管线的第一命中层跑通：用透明容器里零解压可得的 CRC-32 加未压缩大小去匹配 DAT，产出带**置信度**与**依据**的**候选**，并在中立库里建立**作品**与**发行版**。维护者第一次看到真实的命中率。

关键约束：No-Intro 按去头哈希，TOSEC 按含头原样哈希。必须同时计算两套，否则会丢掉全部 TOSEC 汉化条目。

**Blocked by:** 03, 05, 06

**Status:** ready-for-agent

- [ ] 同时按去头与含头两套规则计算哈希并分别匹配
- [ ] 每条候选携带置信度与依据——命中了哪个数据库的哪条记录、匹配了哪个字段
- [ ] 精确命中的候选自动通过，不需要人工介入
- [ ] 一个变体可以有多条候选
- [ ] 识别结果在中立库中建立作品与发行版，变体指向它所基于的发行版
- [ ] 报告给出每个平台的命中率与未命中数
- [ ] 识别过程不联网、不写任何 ROM 文件
