# 10 — 卡带内部头解析

**What to build:** 哈希未命中时，从卡带 ROM 的内部头取得发行版级的识别结论。汉化补丁通常不改动这些字段，因此即使一个汉化版对不上任何数据库，工具仍能认出「这是哪个游戏」——缺的只是「谁汉化的第几版」。

同时区分**官中版**与**汉化版**：官中版是原厂发行的一个地区版本，属于发行版层，走精确哈希直接过；汉化版是变体，改过字节。

**Blocked by:** 07

**Status:** ready-for-agent

- [ ] 解析各卡带平台的内部头字段，字段偏移与长度有据可查
- [ ] 先做体检报告中变体数量最多的几个平台，其余按报告数据排序
- [ ] 字节序与拷贝机头部在解析前完成归一化
- [ ] 内部头命中产出发行版级候选，置信度低于精确哈希但高于文件名
- [ ] 官中版被识别为发行版，汉化版被识别为变体
- [ ] 内部头与目录声明的平台冲突时记录冲突
- [ ] 头部解析器的测试用真实 ROM 的头部字节，不用手工编造的字节
