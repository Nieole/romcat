# 11 — 文件名规则解析与中文离线模糊匹配

**What to build:** 数据库覆盖不到时的倒数第二层：把文件名里的汉化组名、版本后缀、以及「完美版」「最终版」「中文版」这类噪音词剥掉，用剩下的中文名去与中文离线数据源做模糊匹配。

这一层零成本、可复现、可反复重跑调参数——这三样是模型推断都没有的。模糊匹配会错配，因此结论必须带置信度并进队列。

**Blocked by:** 08, 10

**Status:** ready-for-agent

- [ ] 文件名解析能剥离汉化组名、版本号、以及常见噪音词
- [ ] 剥离规则是配置而非硬编码，维护者能补充自己遇到的模式
- [ ] 中文数据源以离线形式使用，匹配不消耗任何在线配额
- [ ] 模糊匹配用平台与年份做交叉校验，不只看标题相似度
- [ ] 匹配结论带置信度与依据，一律进入待确认队列
- [ ] 匹配参数可调整并重跑，不需要重新扫描
