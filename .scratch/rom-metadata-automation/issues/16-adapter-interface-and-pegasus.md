# 16 — 适配器接口与 Pegasus 无损往返

**What to build:** 格式互转的地基。每个前端格式是一个自包含的**适配器**，显式声明自己的**能力档位**：只读、只写、双向、无损往返。第一个适配器是 Pegasus，做到无损往返档。

首要交付是**无损导入维护者多年手工维护的元数据**——未知键、扩展键、注释、字段顺序全部原样留存，否则一次往返就会蒸发这份心血。

「无损往返」不可能靠格式本身达成（Pegasus 自己就会静默丢弃数据），只能靠导入时保存的原文件快照。

**Blocked by:** 05, 15

**Status:** ready-for-agent

- [ ] 适配器是一个统一接口，能力档位对使用者可见
- [ ] 导入保留中立模型表达不了的一切：未知键、扩展键、注释、字段顺序
- [ ] 导入时保存原文件快照，导出时以快照为基线还原表达不了的部分
- [ ] 往返测试通过即认定为无损往返档，未通过则自动降档——档位是断言不是声明
- [ ] 导出时避开会被静默丢弃的写法：评分的百分号、人数区间、日期精度
- [ ] 导出遵循作品级收敛：一个条目、多个文件、默认启动首选变体
- [ ] 首选变体规则为汉化优先于官中优先于日版，可被裁决覆盖
- [ ] 检测到主库元数据被外部修改时警告维护者，不静默覆盖
- [ ] 附属内容与非游戏资产入库但不导出为前端条目
