# 01 — 库体检报告

**What to build:** 维护者能对整个主库跑一遍只读扫描，拿到一份报告，第一次真正看清 10TB 里有什么：每个平台的文件数与容量分布、扩展名构成、透明容器与压缩镜像与裸文件各占多少、以及有多少文件根本不该进库。报告还要抽样读取各类文件的头部，告诉维护者头部解析在真实文件上到底能不能用。

在此之前，所有关于「先做哪几个平台」的判断都基于外部资源站的全站分布而非这个库，因此这张报告是后续一切优先级排序的前提。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 核心能力以独立的库加命令行两种形式提供，界面不是使用它的唯一途径
- [ ] 遍历整个主库不修改任何文件，也不依赖网络与任何 DAT
- [ ] 报告给出按平台目录的文件数与容量分布
- [ ] 报告给出扩展名构成，并区分透明容器、压缩镜像与裸文件三类
- [ ] 报告标出疑似不该入库的内容：重复拷贝、文档、模拟器本体、半截下载
- [ ] 对每类文件抽样读取头部并报告解析成功率
- [ ] 遍历并发到打满磁盘带宽，且可中断可续跑
- [ ] 路径处理跨平台，Windows 上正确处理超过 260 字符的路径
- [ ] 认不出平台的文件照常计入报告，平台未知不构成跳过的理由
