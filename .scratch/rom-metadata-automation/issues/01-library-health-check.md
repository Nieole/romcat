# 01 — 库体检报告

**What to build:** 维护者能对整个主库跑一遍只读扫描，拿到一份报告，第一次真正看清 10TB 里有什么：每个平台的文件数与容量分布、扩展名构成、透明容器与压缩镜像与裸文件各占多少、以及有多少文件根本不该进库。报告还要抽样读取各类文件的头部，告诉维护者头部解析在真实文件上到底能不能用。

在此之前，所有关于「先做哪几个平台」的判断都基于外部资源站的全站分布而非这个库，因此这张报告是后续一切优先级排序的前提。

**Blocked by:** None — can start immediately.

**Status:** done

**收尾（2026-08-31）**：工头抽检三条探针全过（提交在、工作区干净、只读保证有测试兜底），逐条验收对照见下。两条带保留：并发「打满带宽」未获证明（挂账 D9），Windows 真机路径形式未验（票 28）。另有一处缺口在盖章后补掉：完整重复明细导不出来（挂账 D10，已 resolved）。

- [x] 核心能力以独立的库加命令行两种形式提供，界面不是使用它的唯一途径 —— workspace 分 `crates/core`（库）与 `crates/cli`（二进制），工头抽检确认
- [x] 遍历整个主库不修改任何文件，也不依赖网络与任何 DAT —— 测试 `遍历不改主库一个字节`、`断点绝不落在主库里`、`报告不许写进主库`、`断点落在主库内直接拒绝开工`
- [x] 报告给出按平台目录的文件数与容量分布 —— 测试 `按平台目录给出文件数与容量分布`；真库实测产出 40 个平台目录的分布
- [x] 报告给出扩展名构成，并区分透明容器、压缩镜像与裸文件三类 —— 测试 `扩展名构成区分三类`；真库实测 563 个扩展名
- [x] 报告标出疑似不该入库的内容：重复拷贝、文档、模拟器本体、半截下载 —— 测试 `疑似不该入库的内容被标出来`；真库实测 1,881 组重复、6,216 份文档、1,069 个模拟器本体
- [x] 对每类文件抽样读取头部并报告解析成功率 —— 测试 `头部抽样报出各类的解析成功率`；真库实测 16 类，成功率 0%–100% 均如实报出
- [x] 可中断可续跑 —— 测试 `中断后能从断点接着扫`、`并发数不影响结论`。**「打满带宽」这半条未被证明**：真机实测 CPU 仅 2.7%，确认是 I/O 受限，但没有证据表明默认并发值把带宽跑满，且提高并发的单侧检验失败（缓存效应淹没）。见挂账 D9
- [x] 路径处理跨平台 —— 测试 `超过_260_字符的路径照样扫得到`；真库实测确有 1 条超 260 字符的路径。**Windows 真机未验**，见票 28
- [x] 认不出平台的文件照常计入报告 —— 真库实测报告里有「（平台未知）27 个、39.68 GiB」一行


## 挂账裁决（2026-08-31 逐条确认）

- **D1 命名** — 保持 `romcat`：核心库 `romcat-core`、命令行 `romcat-cli`、二进制 `romcat`。`cat` 对得上「中立库 catalog」这个事实来源。
- **D2 断点形态** — 整份快照而非增量日志：有明确的一致点，续跑不可能算重。票 02 之后断点只剩待扫目录、扫描代号与累计耗时，尺寸那半个理由已消失。
- **D3 去重判据** — 维持「同名 + 同大小」，零额外读盘。**票 07 有了 CRC-32 与沉淀库之后再收紧**，那时才有真正的依据。
- **D4 探针深度** — 只看魔数与校验和。这票要回答的是「解析器在真实文件上能不能用」，真正的识别归票 07–10。报出的成功率比真实识别率乐观，报告标题已写明。
- **D5 平台映射** — 要做，且是票 05 与 07 的**前置**而非可延后的便利功能。已写进 ADR-0011 的修订段。
- **D6 工作目录** — 一条跨平台链：`$ROMCAT_HOME` → `%APPDATA%\romcat` → `$XDG_DATA_HOME/romcat` → `~/.local/share/romcat`。macOS 上不合 Apple 惯例，可接受。
- **D7 「裸文件」不在词表** — 已补进 `CONTEXT.md`。
- **D8 中文占比无票认领** — **等票 10 落地后补**，那时才有发行版级依据。现在报告里是「文件名含汉字占比」的粗略代理。
- **D9 并发默认值按错工作类型** — 改成**自适应探测延迟定并发**，已出票 29。
- **D10 重复明细导不出** — 已修，`--dump-duplicates`。
- **D11 明细要不要出 JSON** — 只给文本。用途就是「人照着它决定删哪份」，不留没人调用的死能力。
- **D12 组内路径只在带开关那次记全** — 已由中立库现折解决，不必重扫。
- **D13 「重复拷贝」不在词表** — 已补进 `CONTEXT.md`。
