# 06 — DAT 仓库

**What to build:** 工具在本地维护多个哈希数据库的镜像与索引，并能告诉维护者每个平台有多少条可用记录。这是识别的弹药库。

有两条必须遵守的取数纪律：绝不直连 No-Intro 的 DAT 生成站点（一次参数畸形的请求就会导致永久 IP 封禁），以及 Redump 不能走那个 GitHub 镜像（镜像硬编码了已于 2026 年冻结的旧域名，会少掉数十个系统，且旧站会以「系统存在但无收录」的形式误导）。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] No-Intro 的 DAT 走 GitHub 每日镜像获取
- [ ] 代码中不存在任何指向 No-Intro DAT 生成站点的请求路径
- [ ] Redump 的 DAT 从其现行域名获取，不使用那个硬编码旧域名的镜像
- [ ] 一并纳入 MAME 的哈希数据、TOSEC 与 GoodNES
- [ ] 从代码仓库拉取文件清单时不使用会在一千条处静默截断的接口
- [ ] 能报告每个平台可用的记录条数，含中文汉化条目数
- [ ] DAT 可增量更新，不必每次全量重下
