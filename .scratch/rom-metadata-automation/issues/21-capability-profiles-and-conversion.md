# 21 — 能力档案与格式转换

**What to build:** 每个子库声明它使用的前端与模拟器核心，工具据此决定每个平台的目标格式并在导出时转换。维护者不必记住哪个模拟器吃哪种格式。

**能力档案不只管模拟器**，还必须涵盖目标存储的限制——例如某些文件系统有单文件容量上限，大镜像根本放不进去。这类问题必须在差量预览阶段就暴露，而不是传到一半失败。

格式转换发生在导出侧，主库始终保持原始形态。同一个游戏导到不同设备可以是不同格式。

**Blocked by:** 20

**Status:** ready-for-agent

- [ ] 内置常见前端与核心的能力档案，维护者可选用并手动覆盖
- [ ] 能力档案条目标注数据来源与核实日期——矩阵会随模拟器更新而过时
- [ ] 能力档案涵盖目标文件系统的单文件容量上限与文件名限制
- [ ] 超出目标文件系统限制的内容在差量预览阶段就被报出
- [ ] 转换只产生新文件，主库一个字节不改
- [ ] 差量预览中给出需要转换的条目数与耗时预估
- [ ] 转换产物默认不缓存，可选开启缓存目录
