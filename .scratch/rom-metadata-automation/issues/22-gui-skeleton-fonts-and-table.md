# 22 — 界面骨架：字体子集与十万行表格

**What to build:** 界面层跑起来，并且一次性清掉两个已知风险：中文与特殊符号的显示、以及十万行规模的表格性能。

字体必须打包子集而非读取系统字体——内置字体不只缺汉字，中文标点、假名、罗马数字、带圈数字全都缺；而系统字体路径不可硬编码，且实测各机器的字形覆盖并不一致。

排序、筛选、分页一律下推到数据库层，内存里永远只有当前视口的内容。

**Blocked by:** 12

**Status:** ready-for-agent

- [ ] 界面库版本不低于修复了中文输入两个致命缺陷的那一版
- [ ] 字体以子集形式打包，覆盖简体、繁体、假名，以及游戏标题中常见的特殊符号
- [ ] 界面上不出现豆腐块，含中文标点、罗马数字、带圈数字、音符与星号
- [ ] 十万行表格虚拟滚动流畅，可用合成数据验证
- [ ] 排序、筛选、分页在数据库层完成，内存占用与总行数无关
- [ ] 退出前正确关闭输入法状态，避免组字过程中关窗导致崩溃
