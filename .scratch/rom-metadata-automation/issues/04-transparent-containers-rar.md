# 04 — 透明容器：rar 头部自实现解析与分卷

**What to build:** 工具同样能不解压读出 rar 内部文件的校验和、大小与文件名，并把分卷压缩的多个分卷视为一个透明容器而不是一堆孤立碎片。

头部解析自己实现，不引入内嵌 UnRAR 源码的第三方库——那份许可会传染，且在部分发行版中被归为非自由软件。工具只需要读头，不需要解压，因此完全可以绕开。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 自行实现 RAR4 与 RAR5 的头部解析，不依赖内嵌 UnRAR 源码的库
- [ ] 不解压即可读出内部文件的校验和、未压缩大小与文件名
- [ ] RAR5 分卷时，非末段记录的是打包后数据的校验和——必须识别这种情况并拒绝用它比对 DAT
- [ ] RAR5 仅提供 BLAKE2sp 而无 CRC-32 时，该容器被标记为需要完整解压才能识别
- [ ] 正确区分三种分卷形态：RAR 分卷、7-Zip 的通用字节切分、以及 ZIP 官方 split
- [ ] 分卷的多个文件在体检报告与后续成型中被视为一个容器
