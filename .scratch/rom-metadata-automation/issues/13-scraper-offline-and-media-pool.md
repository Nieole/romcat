# 13 — 刮削器离线档与媒体池

**What to build:** 在**识别**结论的基础上取得元数据与媒体。离线策略档案只用本地数据完成，全库刮削不消耗任何在线配额。所有媒体按内容哈希进入**媒体池**，文件名不再是媒体的主键——因为各前端的媒体匹配键在文件名、标题、标签之间横跳，且净化函数多对一不可逆。

多个数据源按字段级优先级合并，结果持久化缓存。

**Blocked by:** 07

**Status:** ready-for-agent

- [ ] 离线档只用本地数据源，运行时不发起任何网络请求
- [ ] 多个数据源按字段级优先级合并，优先级可配置
- [ ] 刮削结果持久化缓存，重跑不重新计算
- [ ] 媒体按内容哈希存入媒体池，中立库只记录映射
- [ ] 同一份媒体被多个条目引用时只存一份
- [ ] 识别与刮削是两个可分别重跑的阶段
