# 19 — 同步计划器与差量预览

**What to build:** 一个纯函数：输入选择集、上次导出的**清单**、目标设备的实际状态，输出操作计划——也就是**差量预览**。产品要求的预览和这个函数的返回值是同一个东西，不是两套需要保持同步的东西。

它也是唯一能守住那条硬约束的地方：**只碰清单里记录过的、工具自己导出的文件**。维护者手动拷进 SD 卡的内容、模拟器存档、金手指、截图——清单之外的一切对工具不存在。

**Blocked by:** 18

**Status:** ready-for-agent

- [ ] 计划器是纯函数，不进行任何文件系统写入
- [ ] 差量预览给出将新增几个占多少容量、删除几个腾出多少容量、净变化多少
- [ ] 计划中的删除项只可能来自清单，清单之外的文件永不出现在删除列表中
- [ ] 目标上的意外变化（清单说有、实际没了）被报告而非静默补回
- [ ] 选择集超出目标容量时给出超出量与按体积排序的裁剪建议，不自动截断
- [ ] 有测试构造各种状态组合，断言「只碰清单内文件」这条性质
