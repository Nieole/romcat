# 18 — 子库与选择集

**What to build:** **子库**成为持久实体：每台目标设备一个定义，带目标路径、前端格式、容量上限，以及由**规则**加**例外**组成的**选择集**。

规则的价值在可重放——写下「所有某平台的汉化版」之后，主库新增符合条件的内容下次自动进入，不必重挑。例外处理规则表达不了的个人口味，且**优先于规则、永久记住**。

**Blocked by:** 16

**Status:** ready-for-agent

- [ ] 子库是持久实体，配置一次可反复使用
- [ ] 规则可按平台、语言、评分、年份、体积、标签等条件描述
- [ ] 主库新增符合规则的内容后，该内容自动落入对应子库的选择集
- [ ] 手动增删的例外优先于规则，且不会被规则重算覆盖
- [ ] 一个主库可同时存在多个子库，互不干扰
- [ ] 能查看某个子库当前选中了多少条、共多少容量
