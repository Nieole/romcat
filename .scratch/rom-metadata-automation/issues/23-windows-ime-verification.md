# 23 — Windows 真机中文输入法验证（人工）

**What to build:** 在 Windows 真机上人工验证中文输入法的实际表现。**这一项自动化无法完成**——界面自动化在应用层注入事件，而输入法位于操作系统与应用之间，注入的文本根本不经过输入法。

它是一道闸门：如果验证失败，界面层需要更换，那就不应该在验证之前把队列界面盖起来。已知风险是该平台上默认走旧输入法通路，且主流中文输入法的候选窗定位存在长期未决、与修复者实测结论相冲突的问题。

**Blocked by:** 22

**Status:** ready-for-human

- [ ] 在 Windows 真机上用日常使用的中文输入法测试单行与多行输入
- [ ] 验证候选窗定位是否跟随光标
- [ ] 验证组字过程中滚动表格是否丢字
- [ ] 验证回车上屏不多插换行、组字中退格不误删已有文字
- [ ] 验证特殊符号能否输入
- [ ] 若验证失败，评估更换界面层的目标——不应换用走同一底层通路的方案
