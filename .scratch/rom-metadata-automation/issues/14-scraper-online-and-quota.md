# 14 — 刮削器在线档与配额守护

**What to build:** 在线策略档案，维护者可手动切换。它主要用于补媒体资源——离线数据源不含图片。

在线档对这个库有结构性风险：主流刮削源有专门的「当日未识别 ROM 配额超限」错误，配额同时按账号与 IP 计，多账号轮换会导致永久封禁——而汉化版在这些源眼里正是未识别 ROM。因此在线档必须默认限流，并把配额超限当作硬停止而非重试信号。

**Blocked by:** 13

**Status:** ready-for-agent

- [ ] 离线档与在线档在任务级别可手动切换，字段级优先级可单独覆盖
- [ ] 在线档默认限流，并发与频率有明确上限
- [ ] 配额超限被识别为硬停止，不重试、不换账号
- [ ] 只对已确认的条目发起在线请求，未识别的变体不消耗配额
- [ ] 请求结果进入同一份持久化缓存
- [ ] 网络失败不影响已完成的部分，可续跑
