# 15 — 标题集合与显示、排序标题

**What to build:** 中立库中标题永远是**标题集合**——每条带语言、地区、来源与类型，而不是一个单值字段。导出时按优先级选出**显示标题**：中文译名、官方英文名、日文原名、文件名。

两条容易做错的地方：**显示标题的来源与首选变体解耦**——即使默认启动的是汉化版，中文标题仍取**官中版**的官方译名，绝不用汉化版文件名里的名字；以及**排序标题**必须独立生成，中文标题按码位排等于乱排。

**Blocked by:** 13

**Status:** ready-for-agent

- [ ] 标题以集合形式存储，每条带语言、地区、来源、类型
- [ ] 显示标题按中文、官方英文、日文、文件名的顺序回退
- [ ] 中文标题优先取官中版的官方译名，而非汉化版文件名
- [ ] 排序标题独立生成，中文条目排序结果符合预期
- [ ] 同一作品存在多个中文译名时有确定的选定规则
- [ ] 中文名的匹配结论带置信度，低置信度可进入队列
