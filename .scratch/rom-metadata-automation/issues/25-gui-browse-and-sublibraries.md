# 25 — 界面：库浏览与子库管理

**What to build:** 维护者能在界面里浏览整个主库、按平台与合集筛选、查看与编辑条目元数据，并管理**子库**——编辑选择集的规则与例外、查看**差量预览**、触发同步。

所有元数据编辑收敛在这里完成，主库的元数据文件不再是编辑入口。

**Blocked by:** 21, 24

**Status:** ready-for-agent

- [ ] 能浏览主库并按平台、合集、语言、识别状态筛选
- [ ] 能查看与编辑条目的元数据，含标题集合与首选变体
- [ ] 能创建与编辑子库，含规则与例外
- [ ] 差量预览在界面中呈现，同步从这里触发
- [ ] 容量超限时在界面上给出裁剪建议
- [ ] 媒体资源在界面中可见，能确认某条目缺哪些媒体
