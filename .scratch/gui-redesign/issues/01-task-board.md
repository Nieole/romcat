# 01 — 任务台

**What to build:** 点「排差量预览」窗口不再僵住。它进一条任务队列，屏上看得见进度、随时按得停，期间浏览、筛选、看详情照常用。

这一票立的是整份规格的基础设施：核心库里那几个长入口（扫描 37.1 分钟、识别 65.5 秒、刮削、同步、排差量）统一接受一个**报进度 + 能停**的把手。这一票只把**排差量预览**这一个接上去——它是现成的、几秒钟就跑完、而且现在正好是那个僵住窗口的元凶（挂账 D156）。其余长入口在各自的票里接。

「能停」的判据比「能取消」严格：**要停在干净的地方**，下次接着跑不重做已经完成的部分，也不留半截状态。

任务在画帧那条线程之外跑。任务屏列出进行中的与历史的，各自带耗时。

**Blocked by:** 无 —— 可立即开工
