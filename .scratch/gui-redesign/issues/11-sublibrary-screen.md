# 11 — 子库屏重做

**What to build:** 子库屏一台设备一张卡：目标路径、前端格式、容量条、待同步步数、同步按钮。**选择集只读展示**——要改按「改选择」，跳回浏览屏，这个子库的规则已经预填在筛选器里；调完按「更新到子库」原样带回。

现在这一屏一屏塞了八样东西（子库列表、名字/路径/格式/容量/类别表单、规则增删、例外记撤、差量步骤表、容量账、同步、删除确认），而且没有明显的先后顺序——用户的原话是「操作逻辑看不懂」。**根因是它把「选什么」和「送到哪」混在了一起。**

拆开之后：**选什么**归浏览屏，**送到哪**归这一屏。于是这一屏从八个概念降到三个：选哪台、配目标、排差量后同步。

容量条分三段看得见：**选中的、清单之外的、上限**。

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] 一台设备一张卡，目标路径、格式、容量、待同步步数一眼看得见
- [ ] 容量条三段（选中 / 清单之外 / 上限）各自标得出数
- [ ] 点「改选择」跳到浏览屏，**筛选器里预填的是这个子库的规则**
- [ ] 在浏览屏调完按「更新到子库」，规则**原样带回**，选出来的东西与屏上一致
- [ ] 例外（含进来 / 排除掉）在浏览屏上手动加减，子库屏如实显示有几条
- [ ] 排差量与同步走**任务台**：带进度、能停
- [ ] 差量步骤看得见，超长时能全部展开
- [ ] 目标不许落在主库里（ADR-0004），落了当场拦下
- [ ] **目标设备一律用本地 fixture 目录模拟**，测试里绝不碰真实设备或 SD 卡
- [ ] 门禁命令全绿（带 `--all-features`）
