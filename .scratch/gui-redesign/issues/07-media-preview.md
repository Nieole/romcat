# 07 — 详情面板的媒体预览

**What to build:** 详情面板里**直接看得见封面与截图**，不必照着路径去文件管理器里开。视频显示成一张抽出来的首帧加一个播放标，点一下用**系统默认播放器**打开。

真库的媒体池现在 9.5 GB：342 张 jpg、98 张 png、**178 个 mp4**。视频是真需求。

**不在窗口里解码播放。** 那要 ffmpeg 绑定，依赖涨一大截且 Windows 构建麻烦（用户的主力机）。抽首帧走**外部 ffmpeg**，**找不到就退化成占位图标**——不当硬依赖，不新增 Rust 依赖。

抽出来的首帧按内容哈希缓存进**媒体池**，不重复抽。
