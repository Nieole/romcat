# 12 — 布局可调与视觉一致性收尾

**What to build:** 拖动面板之间的边界调整各区大小，关掉再打开还是那个样子。以及把**置信度**的颜色语言在五屏里对齐——同一档在哪一屏都是同一个颜色、同一个词。

面板边界的位置持久化在**工作目录**里，不是中立库——中立库整份可再生，界面偏好放进去会被某次重扫抹掉。

置信度四档：**高置信 / 中置信 / 低置信 / 还没识别**。「还没识别」是词表里那个第三态——既不是「未命中」（撞过没撞上，是结论），也不是「无判据」（拿不到可撞的东西）。

**Blocked by:** 03、09、11

**Status:** ready-for-agent

- [ ] 浏览屏、待确认屏、子库屏的面板边界都拖得动
- [ ] 拖动后的位置关掉再打开还在，**存在工作目录里不存在中立库里**
- [ ] 拖到极限时不塌陷、不把某一区挤没
- [ ] 置信度四档的颜色与文案在五屏里**逐字一致**
- [ ] 颜色不是唯一线索——每处都有文字标签，色觉障碍下仍读得出
- [ ] 窗口标题写明当前开的是哪一份库与哪一屏
- [ ] 键盘焦点在所有可操作件上都有可见状态
- [ ] 门禁命令全绿（带 `--all-features`）
