# 01 — 中文离线索引多存几样，别名先端到端

**What to build:** 中文离线源撞上一个条目之后，那个条目的**别名**进**标题集合**——同一部作品的多个叫法，用户搜哪个都找得到。

为了做到这件事，本机那份中文离线索引要开始留住它一直丢掉的东西：条目的**简介**、以及 infobox 里的**类型**、**开发商**、**发行商**。这一票只**取到并存下来**，真正把它们产出去是后面几票的事——但存储、结构版本、索引这条路要在这一票里一次走通，别名就是走通它的那颗曳光弹。

别名是**变体**这一层的字段（与中文名同层，依据说的是「这个文件的正题撞上的」），所以这一票**不碰作品层的任何机制**。

结构版本要往上走一格。这份索引是**可再生**的：版本对不上就从本机那份原件整份重建，不走顺序迁移，也**不重新下载**。

**Blocked by:** 无 —— 可立即开工

**Status:** ready-for-agent

- [ ] 跑一趟**离线档**刮削，撞上的变体在**变体锚点**上多出别名，且它们进了标题集合
- [ ] 撞不上中文条目的变体**一个新字段都不产出**
- [ ] 这一趟的网络请求数为 **0**
- [ ] 索引里存得下简介、类型、开发商、发行商；结构版本已 +1
- [ ] 拿一份**旧结构版本**的索引打开，它**自动从本机原件重建**，没有网络请求、也没有要求用户重新下载
- [ ] infobox 解析在解析处有内联单元测试，盖住：单值、多值块、顿号分隔、缺键、空值、键名带空格
- [ ] **输入指纹**盖住了新的解析——改了取哪些字段之后重跑，撞上过的锚点会**重采**而不是被缓存跳过
- [ ] 门禁命令全绿
