# 05 — 一次裁决管住同一次匹配的全部字段

**What to build:** 模糊匹配撞错了的时候，用户在**待确认队列**里对中文名下**一次裁决**，同一次匹配带来的简介、类型、开发商、发行商**跟着一起改**——不必对同一次误撞裁决五遍。

这几个字段不是各自独立撞出来的，它们**同生共死**：都来自变体层那一次匹配、同一个条目号。所以裁决的粒度该是「这次匹配对不对」，而不是「这个字段对不对」。眼下的队列是按字段排的，用户改完中文名，那条错匹配带来的另外四个字段还留在库里。

这一票不放松置信度的口径：模糊匹配来的仍然是**中置信**、仍然不自动通过。改的只是**一条裁决管多大范围**。

**Blocked by:** 03、04

**Status:** done
