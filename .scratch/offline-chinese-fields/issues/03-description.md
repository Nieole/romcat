# 03 — 简介

**What to build:** 用户在前端里点进一个条目，**有中文简介可读**——而这一趟一个网络请求都没发。

这是整份规格的正题。实测本机那份数据：112,562 条游戏条目里 **105,981 条带中文简介（94.2%）**，中位 338 字。用户手上那份维护多年的元数据，每条也都有简介（样本中位 1354 字）——这一票就是让工具自己产出同一个成色的东西。

简介挂**作品**锚点（票 02 立好的那条路）。

两处边界要处理：

- **长度**。实测最长 9,962 字。存储与导出都不能因为超长条目变得不可用，界面上的列表仍要滚得动。闸设在多少由实现定，但要说得出理由，并且**被截断这件事要让用户看得见**，不能悄悄砍一半。
- **排版**。数据源自带的换行与全角空格**原样保留**——导出到前端里不该变成一坨。
