# 06 — 报告说实话

**What to build:** 刮削报告不再把用户往在线档推。

它现在说的是「**离线档补不上简介、类型与开发商**——换在线档跑一趟才补得上」。这句话是错的：那三样全在本机那份数据里（94.2% / 99.7% / 83.8%）。调研的原话是「不含**图片**」，两个离线数据源各缺一样，被并成了一句。

代价是实打实的：用户被推去烧在线配额换英文简介，而中文简介就躺在本地。

改成如实说：**离线档补不上的是图**。同时报告要新增这一层到底值多少——从中文离线源补上了哪几个字段、各多少条、**按平台的覆盖**。按平台那一栏是给「老平台补不上」这件事一个交代：那是数据源本身浅（老平台条目数以几十计），不是匹配算法的锅，报告不点名的话用户会怪错地方。

排在最后，是因为字段不齐就报不准。
