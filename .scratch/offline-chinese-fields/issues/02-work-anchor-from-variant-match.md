# 02 — 作品层拿得到变体撞出来的中文条目

**What to build:** 游戏**类型**出现在**作品**这一层。同一部作品的两个变体撞到同一个中文条目时，作品锚点上**只有一份**类型，不是两份。

这一票立的是整份规格的骨架：**撞在变体层、挂在作品层**。

- 撞只能在变体层做——高信号只有一处，就是文件名剥出来的**正题**（中文的），拿它撞中文条目的中文名与别名。作品层手里只有 DAT 给的名字（多为英文/罗马字），而实测数据源里只有 **15.4%** 的条目带纯拉丁别名，作品层自己撞连六分之一都撞不上。
- 但简介、年份、开发商、发行商属于作品——那是作品锚点的定义（跨平台跨地区都成立的东西挂这一层）。挂到变体上就是同一部作品的每个变体各存一份重复内容。

于是中文离线源**在两层都参加**：变体层照旧撞、出中文名与别名，并把撞上的**条目号**留作结论的一部分；作品层不自己撞，读「这个作品名下的变体撞到了哪些条目号」，取其中最多数的那一个，产出作品级字段。

**这是整份规格里唯一牵动刮削主体形状的一条**：作品层的主体要带上它名下变体的匹配结果，且**变体层必须先于作品层采集**。用最简单的单值字段（`游戏类型`，覆盖率 99.7%）把这条路跑通。
