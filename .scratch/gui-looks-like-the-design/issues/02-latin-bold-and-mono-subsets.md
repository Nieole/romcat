# 02 — 打包拉丁粗体与拉丁等宽两份子集

**What to build:** 维护者在屏上看得出层次：标题里的拉丁字母与数字是粗的，路径、哈希、
容量与数量等宽对齐、一列数字扫一眼能比大小；中文一律常规字重，程序只多几百 KB。

**Blocked by:** 无 —— 可立即开工

**Status:** ready-for-agent

⚠️ **裁定（2026-09-13）：不打包中文粗体。** 中文的层次靠字号、颜色与间距，设计稿已经
按这个结果画。

⚠️ **字重合成必须关掉**，否则 egui 会给中文画出假粗体——那正是这条裁定要避免的东西。

- [ ] 两份小子集由现有那条子集脚本产出，同样的输入产出同样的字节；许可跟着二进制走
- [ ] 粗体族里只有拉丁与数字，中文回退常规体；屏上没有合成出来的假粗体
- [ ] 等宽只用于路径、哈希、序列号、数量与容量；一列数字对得齐（同宽数字）
- [ ] 二进制体积增量量出来写进票里
- [ ] 字体检查那条路照旧跑得过，豆腐块没有多出来
