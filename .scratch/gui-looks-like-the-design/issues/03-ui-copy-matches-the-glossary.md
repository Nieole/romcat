**What to build:** 维护者在屏上读到的每一句都是他用得上的话：按钮是动词、收场四档与
文档里是同一套词，屏上不再出现写给开发者的解释、`**` 与 ADR 编号。

**Blocked by:** 无 —— 可立即开工

**Status:** ready-for-agent

要改的字（词表 2026-09-11 与 09-13 两轮裁定）：认领新主库 → **添加主库**；
折标题 → **整理标题**；按停了 → **已取消**；停在半路 → **部分完成**；
在访达中显示 → **在文件系统中打开**。

⚠️ **收场四档只有一处落字**（`Ending` 那个渲染），界面与命令行都读它——别在界面里再写一份。

⚠️ 断言旧字串的测试要跟着改，那是这张票的一部分；注释与测试名里的旧词不必全改。

⚠️ **写新文案之前先过一遍词表的 `_Gate_` 那 12 行**：`machine-checks-premises/02` 会给门禁
加一条，新写的 `.rs` 里标识符与**字符串字面量**撞上 `_Gate_` 词就当场报红（只扫新代码）。
开场（启动屏、欢迎页、首屏、库选择器）、工序（步骤、阶段、流水线）、任务台（作业、
后台任务、任务列表、线程池）、差量预览（预演、确认页）、批（批次、批号）、媒体池
（图片目录、资源库）都在里面——这批观感票新写的文案量最大，撞上的机会也最大。

⚠️ **本票要改的那几个词恰好没进 `_Gate_`**（「认领」在**添加主库**的 `_Avoid_` 里但没有
`_Gate_` 行，收场四档同理），所以机器不会替你找，逐处 grep 是这张票自己的活。
