# 27 — 库体检：概要与明细

**What to build:** 维护者在库屏上看到一份**库体检**概要：重复拷贝、目录与内容平台不符、
成型存疑、不可读、未纳入管理的目录、附属文件落单、非游戏资产、疑似同一作品——每一格点
进去看明细。它是只读检查，只报告、不处理。

**Blocked by:** 06

**Status:** ready-for-agent

⚠️ **数不在界面里算**：报告本来就有给界面吃的那一份形态，界面只画它。

⚠️ **重复拷贝只发现并报告，绝不自动删除**（词表）；主库只读（ADR-0004），要清理请人自己
去文件系统里做。同一个作品的两个不同转储**不算**重复拷贝。

- [ ] 概要八格，数字来自核心库的报告；还没扫描时是空态
- [ ] 每一格点进去有明细：路径、原因、数量，能在文件系统里打开
- [ ] 重复拷贝按可腾出的空间排序，每组列得出全部路径，屏上写明不会自动删除
- [ ] 明细能导出成一份清单
