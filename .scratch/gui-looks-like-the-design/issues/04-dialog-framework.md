# 04 — 弹层的统一写法

**What to build:** 维护者在任何一处弹出的对话框——添加主库向导、刮削、子库目标设置、
手动例外、合集、优先级、导出照写、移除根、成型纠正、平台纠正、库体检明细、导入元数据、
删除确认、移出此作品——长得是同一套：同样的遮罩、同样的标题与页脚、同样的几档宽度、
Esc 一层一层退，键盘走得通。

**Blocked by:** 01（令牌）、02（字体）

**Status:** done

⚠️ **这是一张地基票**：它先落地，后面每一张带弹层的票（05、21、22、27、28、29、30、31…）
都照它办，**不许各写各的**。并行开工时若这张还没合，那几张先按设计稿画，收尾时对齐到这一套。

⚠️ **宽度只取令牌里那四档**（520 / 620 / 720 / 840），不许现编一个数。

⚠️ **弹层里也有输入框**：中文输入放在不会被回收的区域里（ADR-0005），Esc 与焦点顺序
要在这一层一次做对，别在每个弹层里各写一遍。

- [x] 一处统一的弹层写法落地：遮罩、标题 + 说明、内容区可滚动、页脚按钮排布
      证据：`crates/gui/src/dialog.rs`（`Dialog` / `Footer` / `Button` / `Width` / `screen_has_keys`，
      模块文档写清怎么用、这一层替每一处做掉哪几件事，用法是一段**编译过的** `no_run` 文档示例，接口一改就编不过）；
      遮罩取令牌 `scrim`（`look::scrim`），主按钮取 `accent` / `accent-hover` / `on-accent`（`look::primary_button`，
      「下一步」「开始扫描」「开始刮削」「落下」标上），三样都接进 `look` 的逐项比对与变异测试、从 `NOT_YET_USED` 划掉；
      `tests/dialog.rs` 八条，其中 `页脚上的主按钮画成强调色_其余几颗不是`。
      不是一张「种类 → 画法 / 动作」的分发表，是各屏自己的类型各带动作枚举（规格原句与此不同，挂单 `Q669`）。
- [x] 宽度取自令牌的四档；内容比一屏长时内容区滚动而不是把页脚顶出去
      证据：`tests/dialog.rs::宽度只取令牌里那四档`（期望值抄票面 520 / 620 / 720 / 840，四档各画一层量宽）、
      `窗口比那一档还窄时弹层收在窗口里`（720 宽的窗口里最宽那一档不出窗口）、
      `内容比一屏长时内容区滚动而页脚不被顶出去`（三百行：弹层不出窗口、页脚看得见、最后一行在裁剪区外；
      滚到底最后一行露出来，页脚一个点都没动）。刮削取 720 那一档（设计稿 680 不在四档里）。
- [x] Esc 关最上面那一层；打开时焦点落进弹层，关闭后回到原来那颗按钮
      证据：`tests/dialog.rs::退出键一次只关最上面那一层`（两层叠着，一下只退一层）、
      `打开时焦点落进弹层_关掉之后回到原来那颗按钮`（Tab 到按钮、空格打开、焦点落进里头那一框、Esc 后回到那颗）、
      `弹层里的输入框滚出视口也不被回收`（ADR-0005）；产品侧 `tests/program.rs::按下添加主库焦点就落在起名那一框里_不用先拿鼠标点进去`。
      保留：**鼠标点开**的弹层关上后焦点不回到那颗按钮——egui 点一下按钮不给它焦点（挂单 `Q668`）。
- [x] 添加主库向导与刮削面板改写成用这一套（这两处是现成的样板）
      证据：`claim::Wizard::show`、`scrape::Panel::show` 走 `Dialog`，领域那一半一行没动。
      `tests/program.rs` 34 条全绿（向导原有测试原样，另添 `向导开着时按退出键等于按了算了_工作目录里一个文件都不多`），
      `tests/browse.rs` 49 条全绿（刮削原有测试原样，另添 `刮削面板开着时按退出键就收起_旋钮留在原位`）。
      刮削从浏览屏底栏换成弹层，`layout::SCRAPE` 那条边界随之拿掉（七条变六条），`tests/layout.rs` 里专测
      「两块底栏一起拖到底」的那一条删了。连带：待确认屏的计划书也收进这一套、裁决记录浮窗没收（`Q661`，托票 18）；
      刮削按钮换字（`Q665`）；排上之后弹层不自己关（`Q664`，那颗按钮悬停里「期间浏览、筛选照常」改成了实话）；开场从此装上观感基线（`Q666`）；
      走向导时开场那张表照旧让位（`Q667`，托票 05）。

      `tests/queue.rs::计划书开着时按退出键撤掉计划书_一个字都不写_关上之后逐条键盘照常`（计划书开着按 `N`
      不落、Esc 撤掉计划书一个字不写、关上之后 `N` 照常落下）。保留：那道门看的是上一帧（挂单 `Q662`）。
