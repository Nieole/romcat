# 04 — 弹层的统一写法

**What to build:** 维护者在任何一处弹出的对话框——添加主库向导、刮削、子库目标设置、
手动例外、合集、优先级、导出照写、移除根、成型纠正、平台纠正、库体检明细、导入元数据、
删除确认、移出此作品——长得是同一套：同样的遮罩、同样的标题与页脚、同样的几档宽度、
Esc 一层一层退，键盘走得通。

**Blocked by:** 01（令牌）、02（字体）

**Status:** ready-for-agent

⚠️ **这是一张地基票**：它先落地，后面每一张带弹层的票（05、21、22、27、28、29、30、31…）
都照它办，**不许各写各的**。并行开工时若这张还没合，那几张先按设计稿画，收尾时对齐到这一套。

⚠️ **宽度只取令牌里那四档**（520 / 620 / 720 / 840），不许现编一个数。

⚠️ **弹层里也有输入框**：中文输入放在不会被回收的区域里（ADR-0005），Esc 与焦点顺序
要在这一层一次做对，别在每个弹层里各写一遍。

- [ ] 一处统一的弹层写法落地：遮罩、标题 + 说明、内容区可滚动、页脚按钮排布
- [ ] 宽度取自令牌的四档；内容比一屏长时内容区滚动而不是把页脚顶出去
- [ ] Esc 关最上面那一层；打开时焦点落进弹层，关闭后回到原来那颗按钮
- [ ] 添加主库向导与刮削面板改写成用这一套（这两处是现成的样板）
- [ ] 一条测试钉住：弹层打开时底下那一屏的快捷键不生效、Esc 关得掉

收挂单 `Q485`：弹层阴影的颜色进不进令牌、取什么值，与阴影形状一起定（票 01 眼下照 egui 默认，`look.rs` 的比对测试里写明了不比）。
