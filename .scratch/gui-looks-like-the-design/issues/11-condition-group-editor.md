# 11 — 条件组编辑器：筛选器就是一棵组

**What to build:** 维护者用可嵌套的**组**来筛：每组挑一种**连接**（全部满足 / 任一满足 /
都不满足），组里摆**子句**（十三个**维度** × 九个运算符）与更多的组；填错时当场告诉他
哪一条不成立，屏上随时看得到「这套筛选写成**规则**是什么样」。

**Blocked by:** 08

**Status:** ready-for-agent

⚠️ **界面不自己解析规则**（ADR-0024）：维度、运算符、连接与文字形式全部来自核心库那一处，
界面只组装再交回去。同一层里不许混用「且」与「或」——要混就套括号，这条由结构本身保证。

⚠️ **评分那一维立着但没有源**：写得出规则，筛不出东西——屏上如实说明，不要藏起来。

- [ ] 十三个维度、九个运算符、三种连接都用得上，组可嵌套
- [ ] 子句当场校验：年份四位数、体积带单位、平台名认不认识、合集在不在
- [ ] 未填写的子句不生效，屏上说明白有几条不生效
- [ ] 屏上实时显示写成规则的那行文字，与核心库的写法逐字一致
- [ ] 只用于浏览的分面（识别结论、整理建议）不写进规则，屏上说明
- [ ] 界面里没有第二处规则解析（测试断言用的是核心库交回来的结果）
