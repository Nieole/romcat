# 11 — 表格按列排序

**What to build:** 维护者点表头就能按作品名、平台、变体数、容量、年份排序，年份未知的
那些永远排在最后。

**Blocked by:** 09

**Status:** ready-for-agent

⚠️ **作品名按排序标题排**，不按显示标题——中文按编码排出来是乱的，词表**排序标题**
那一条正是为这件事立的。

- [ ] 五列都排得动，点第二次换方向，第三次回到默认顺序
- [ ] 作品名按排序标题排；年份未知的在两个方向上都排最后
- [ ] 卡片视图与表格共用同一个排序
- [ ] 搜索时默认按匹配程度排，显式选了排序则以它为准
