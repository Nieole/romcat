# 14 — 右键菜单与全局快捷键

**What to build:** 维护者右键一行或一张卡，拿到这一行的常用动作；键盘上用得动整套快捷键，
按 `?` 随时看得到一张表。

**Blocked by:** 09

**Status:** done

⚠️ **跨平台**：macOS 上是 ⌘，Windows 与 Linux 上是 Ctrl；表上两种都写得出。

⚠️ **快捷键表只有一份**：这张票造它，设置页（票 31）那一节摆的是同一份，不另抄一遍。

收挂单 `Q1060` / `Q1061`：**那一份已经由票 31 造出来了**，在 `crates/gui/src/keys.rs`
（一份数据 `keys::groups()` + 修饰键 `keys::MODIFIER` + 表底那句 `keys::NOTE`），设置屏「快捷键」
一节摆的就是它。这张票**往它里头添**，别另起一份：⌘/Ctrl+1–6、⌘/Ctrl+F、`?`、浏览屏的上下键与
`F` / `E` / `⌘ A` 眼下都不在表上——**接一个才列一个**（表上不许印按不动的键）。
`⌘/Ctrl+,` 票 31 已经接了（`App::shortcuts`，两道门抄的是 `queue::Screen::keyboard`：
有弹层开着不接、光标在文本框里不接），这张票接另外几下时接到同一处去。
`?` 那层弹层照 `dialog::Width::Standard`（620）画，body 调 `keys` 那一份。

⚠️ 票面这一段里「表底那句 `keys::NOTE`」这个说法这一票改了（挂单 `Q1144`）：稿上
`keys::NOTE` 是**弹层的副标题**（`DLG.keys` 的 `sub`），设置屏那一节底下写的是另一句
（`随时按 ? 查看这张表。`，`prototype.html:3301`）。票 31 那时没有弹层，把它摆进了表底。
现在按稿分开：`keys::table` 只画表，两句各归各处（`keys::NOTE` / `keys::SEE_SHEET`）。

收挂单 `Q1140`：**那十项里有两项今天没有下一步**，这一票**不摆**它们——
「加入合集…」那层弹层是票 `13` 的（今天只有筛选栏底下那个格子，范围还是勾中的那一批），
「加入子库…」那层是票 `23` 的（今天全仓只有「存成子库」，那是另一件事）。
与快捷键表那条「接一个列一个」同一条纪律：**屏上不许印一件做不到的事**；
画灰也不行——菜单是按一下就收的浮层，ADR-0005 要的「屏上常驻那条理由」它给不出。
那两票做出来之后各自往 `browse::menu` 那份清单里添一项。

收挂单 `Q1142`：**跟高亮走的那六下只在表格那一路接**，摆着卡片墙时一下都不接
（`⌘/Ctrl+A` 除外——它选的是当前这个筛选，与光标落在哪一行无关）。
真正的阻碍是**高亮存成了行序号**（票 09 的 `focused: Option<u64>`），而表格与卡片墙背后
是两扇窗、两份查询，同一个数在两边指的不是同一行；稿存的是**作品号**（`S.sel`），
所以稿那段 keydown 压根不区分两种视图，卡面选中态稿上也画了（`.gcard[aria-selected]`）。
卡片墙上 `Enter` / `空格` 照旧走得通（Tab 走到一张卡，那张卡自己接）。
要让 ↑↓ 在卡片墙上也走得通，得把 `focused` 换成作品身份——那是票 09 那块地盘上的改动。
