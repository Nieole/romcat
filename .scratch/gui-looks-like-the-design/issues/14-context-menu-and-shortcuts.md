# 14 — 右键菜单与全局快捷键

**What to build:** 维护者右键一行或一张卡，拿到这一行的常用动作；键盘上用得动整套快捷键，
按 `?` 随时看得到一张表。

**Blocked by:** 09

**Status:** ready-for-agent

⚠️ **跨平台**：macOS 上是 ⌘，Windows 与 Linux 上是 Ctrl；表上两种都写得出。

⚠️ **快捷键表只有一份**：这张票造它，设置页（票 31）那一节摆的是同一份，不另抄一遍。

收挂单 `Q1060` / `Q1061`：**那一份已经由票 31 造出来了**，在 `crates/gui/src/keys.rs`
（一份数据 `keys::groups()` + 修饰键 `keys::MODIFIER` + 表底那句 `keys::NOTE`），设置屏「快捷键」
一节摆的就是它。这张票**往它里头添**，别另起一份：⌘/Ctrl+1–6、⌘/Ctrl+F、`?`、浏览屏的上下键与
`F` / `E` / `⌘ A` 眼下都不在表上——**接一个才列一个**（表上不许印按不动的键）。
`⌘/Ctrl+,` 票 31 已经接了（`App::shortcuts`，两道门抄的是 `queue::Screen::keyboard`：
有弹层开着不接、光标在文本框里不接），这张票接另外几下时接到同一处去。
`?` 那层弹层照 `dialog::Width::Standard`（620）画，body 调 `keys` 那一份。

- [ ] 行与卡片上的右键菜单：打开详情、编辑元数据、勾选、收藏、加入合集、加入子库、合并、刮削、在文件系统中打开、复制名称
- [ ] 切屏（⌘/Ctrl+1–6）、搜索（⌘/Ctrl+F）、设置（⌘/Ctrl+,）、快捷键表（`?`）
- [ ] 浏览屏：上下选、Enter 打开、空格勾选、⌘/Ctrl+A 全选筛选结果、F 收藏、E 编辑元数据
- [ ] 输入框获得焦点时不响应单键快捷键（中文输入不被抢）
- [ ] Esc 关掉菜单与弹层，一层一层退
