# 13 — 收藏与合集

**What to build:** 维护者勾一批作品、起个名字就建出一个**合集**，之后能按合集筛、改名、
删除（删除就是把成员全部移出），也能在作品详情里把一个作品移出某个合集。挂不住**内容锚**
的那些（无判据那一档）在屏上明确标出来。

**Blocked by:** 09

**Status:** done

⚠️ **成员关系落沉淀库、锚在内容锚上**：删掉中立库重扫还在、改名挪目录还认得出。
中立库里那两张表是投影。

⚠️ **收藏是那个默认的一组**，与合集同一套机制；它**不是**前端里的用户状态。

- [x] 勾一批建合集、改名、删除（成员全部移出）、加入已有合集
- [x] 按收藏与合集筛选，分面上带数量
- [x] 作品详情里看得到它属于哪些合集，并能就地移出
- [x] 挂不住内容锚的收藏与合集成员在屏上标出来，写明改名或移动后会丢
- [x] 删掉中立库重扫之后成员还在（测试断言）

**验收逐条**

1. 建 / 改名 / 删除 / 加入已有——四样都在两个弹层里。删除＝把成员全部移出，
   **写着它的子库规则一个字不改**（`collection::drop_all` 的文档写着理由：
   删完还可能再建一个同名的回来）。
2. 分面带数量：左栏「合集」那一簇，来源 `Facets::collections`，两个弹层读的是同一份
   （不自己数第二遍）。⚠️ 那个数数的是**变体**不是作品，屏上照实写「N 个变体」
   ——与稿上的「N 个作品」是两个数，挂单 `Q1107`。
3. 详情页那一行合集 + 就地移出：`browse/work.rs` 的 `status_card`，
   回执报的是**真动了几条**（`Applied::changed`）不是计划数。
4. 挂不住内容锚的标出来：详情页每个成员后头「· 只按路径记录」、
   「加入合集」那一层那块警告、加完那份回执各说一处。
   ⚠️ 稿上「其中 N 个只能按路径记录」那个 N **印不出来**（`Q1103`，已裁「不补」）。
5. 删掉中立库重扫成员还在：`crates/core/tests/collection.rs` 的
   `删掉中立库重扫一遍_收藏一条都不少`。**这一条是票 09 留下的，不是这一票挣的**
   （见下「票面本身几处不对」第 3 条）。

**`/code-review` 两轴抓到、这一趟改掉的（挑要紧的）**

- **`check_name` 比「写得进规则」松**，于是 `甲 或 乙` 这类名字建得出来、筛不出东西；
  改名时更坏：沉淀库改完了、投影重建了，第三步 `Clause::build` 失败后那条规则**静默**
  留着指向旧名，而回执报「没有哪条子库规则写着它」——那个子库从此一行都选不出来，屏上不红。
  补了 `BadName::Unwritable`（判据直接用 `catalog::browse::writable_value`，
  **不另写一份**），`rename_in_clause` 那个静默兜底改成往上交错误。

## 收尾（2026-09-22）：分段开关那一处，以及门禁

拿主意的人看完 A 组基线提的：顶部「表格｜卡片」与「不分组｜按平台」该有连起来的视觉效果。

**仓里早就有 `look::segmented`**（设计稿 `.seg`），队列屏、设置屏、子库屏六个调用点都在用；
浏览屏这几处却是 egui 默认的 `ui.selectable_label`——两颗各自独立、没有外框。
**又是「现成的有、没用、另画了一份」**，这一轮第三回。

- 逐个令牌核过 `look::segmented` 画的就是稿上那个 `.seg`（`padding:2px`/`height:24px`/
  `padding:0 11px`/`--r`=6/`--r-s`=4/`sunken`+`line`/选中 `panel`+`ink`+`line-2`），
  并照着队列屏现有基线看过渲染，不是只读代码。唯一出入是稿上选中加粗而全仓一律常规体
  （中文字体预算，早就定的）。
- **改了三组不是两组**：稿上浏览屏有三组 `.seg`，第三组「小｜中｜大」与「不分组｜按平台」
  **并排摆在同一条 `.cbar` 里**，一组连起来一组散着比两组都散着还难看。三组都在浏览屏
  自己的地盘上，别的屏一行代码、一张基线都没动（那一趟 121 张里别的屏 63 条全绿）。
- **撞出 `look::segmented` 自己一条 bug**：它拿 `(“分段开关”, 下标)` 认每一颗，
  而同一个 `Ui` 里摆两组时 `ui.id()` 相同、下标又都从 0 起，于是重号——屏上冒出
  egui 的「First use of Widget ID」红字，按「小」会连着把「不分组」一起按了。
  补法是认身份时带上那颗写的字；**一个像素都不动**（id 只管交互、不进绘制）。
  **这条 bug 所有行为测试都是绿的，是照着重出的图看出来的。**
- `.seg` 那三个令牌**进了 `check_tokens.py`**（此前不在名单里，`Q1083` 那个「绿着但没在看」
  的洞）：核对项 296 → 300，验过改坏一个它会报。

**全仓其余地方核过了**：稿上八组产品 `.seg`（另有两组是稿自己的开发条，不算），
五组本来就在用 `look::segmented`，欠的三组全在浏览屏、已补齐。
剩下的 `selectable_label` 调用点都不是分段开关——下拉里的菜单项（浏览屏卡片排序、
