# 01 — 颜色与尺寸只有一份来源

**What to build:** 维护者打开界面，看到的配色、圆角与字号与设计稿一致；日后要改一个颜色，
只改一份数据文件——设计稿与程序两边偏离时，门禁当场红。

**Blocked by:** 无 —— 可立即开工

**Status:** ready-for-agent

⚠️ **数据不是代码**：这份令牌与 `platforms.toml` / `profiles.toml` / `priorities.toml`
同一条纪律，编进二进制，不在运行时读盘。

- [ ] 两套主题的颜色、平台色、字号、间距、圆角、版式尺寸落在 `romcat-gui` 里的一份 TOML 数据文件里
- [ ] 亮暗两套 Visuals 从它取值；界面里**没有第二处写死的颜色**（置信度四档、平台色、面板底色、描边全收进那一处）
- [ ] 一条测试拿令牌**逐项**比对两套 Visuals；**变异实测**：改令牌里任意一个颜色，这条当场红
- [ ] 设计稿目录那份检查脚本改成读**同一份**文件并跑通；设计稿目录里不再留第二份令牌
- [ ] 门禁全绿（`--all-features`）
