# 04 — 开场照设计稿落地，并立起截图门

**What to build:** 维护者第一次打开程序，看到的开场与设计稿一致：左边一句话讲清工具做
什么加三条承诺，右边只有一个主要操作；添加主库仍是三步向导，点「开始扫描」之前一个
文件都不写。这一屏同时成为**截图门**的第一张基线——之后谁改动了一个像素，门禁就红。

**Blocked by:** 01（令牌）、02（字体）、03（文案）

**Status:** ready-for-agent

⚠️ **弹层的统一写法在这张票里定下来**：一个 Modal、四档宽度（令牌里那四个数），
添加主库向导按它改写；后面每一张带弹层的票都照它办，不各写各的。

⚠️ **截图门有两件事要先定并写进票里**：CI 上没有显卡，用软件渲染；不同平台渲染有细微
差别，因此定**一台出基线的机器**与一个比对阈值。

- [ ] 开场、主库列表、添加主库向导照设计稿排版（三条承诺、名称与目录当场校验、第三步写清读哪儿写哪儿）
- [ ] 弹层统一写法落地，向导按它改写，宽度取自令牌
- [ ] 截图比对在门禁里跑得起来；出基线的机器与阈值写在票里
- [ ] 开场三种状态各一张基线，由拿主意的人对着设计稿点头后入库
- [ ] 挪动一处间距，截图门当场红（变异实测）
- [ ] 收尾时附一张对照图（程序截图 vs 设计稿同一屏）
