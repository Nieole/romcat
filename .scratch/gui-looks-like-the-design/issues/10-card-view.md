# 10 — 卡片视图

**What to build:** 维护者在浏览屏上切到卡片视图，一眼看到封面墙：每张卡上有封面、名称、
平台、年份、变体数、中文身份与置信度；没有封面的显示一张有平台色和标题的**字卡**，
而不是灰色占位块。

**Blocked by:** 09

**Status:** done

⚠️ **大多数作品没有封面**（真库里本地能匹配到的图片只有几百张），所以无封面那一档必须
好看——它是常态不是例外。

- [x] 表格与卡片两种视图切得动，选择下次还记得（`卡片视图选择记在工作目录而不进中立库`）
- [x] 卡片上六样信息齐；勾选框在悬停或已有选择时出现（`卡片视图可切换并画出作品信息`，实际 egui MCP 检查）
- [x] 没有封面时显示字卡（平台色底、显示标题、平台代号水印）（实际 egui MCP 截图）
- [x] 按平台分组与三档卡片大小（卡片工具栏与核心平台排序）
- [x] 「只显示有封面的」是视图开关，**不写进**子库的选择集规则（独立卡片查询窗口，`WorkQuery::to_rule` 不读取该位）
- [x] 键盘可用（Tab 移动、Enter 查看、空格勾选）；这一屏的基线图入库（egui MCP：卡片获焦、Tab 到“选择”、空格后显示“选中 1 条”；`crates/gui/tests/snapshots/browse/cards-dark.png`）
