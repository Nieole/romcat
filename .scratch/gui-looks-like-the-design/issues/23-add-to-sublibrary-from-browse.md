# 23 — 从浏览加入子库与挑选模式

**What to build:** 维护者在浏览里筛到满意，把这一批加进某台设备的子库：可以作为一条
**规则**加入（以后扫描到符合条件的新作品也自动落进来），也可以只把勾选的作品作为
**例外**加入。一个子库通常要分几次加——挑选模式让他换一个平台、点一下就加一条。

**Blocked by:** 20、12

**Status:** done

⚠️ **筛到满意存成子库，规则原样就是那棵组**（词表**组**）：中间不许翻译一道，否则用户
看见的那批与真正导出去的那批对不上。

- [x] 加入对话框：选设备、选加入方式，预估新增多少变体、与已有规则重复多少、加入后多大
- [x] 「加入后多大 / 装不装得下」取的是票 20 那一处口径（`one-criterion-per-thing/01` 之后的那个底），不另算一份
- [x] 已经存在的同一条规则被拦下并说明
- [x] 「加入并继续挑选」进入挑选模式，浏览屏顶部常驻挑选栏（规则数、变体数、容量条）
- [x] 换一个平台再加一条，累计数字当场更新
- [x] 某条规则可以载回浏览编辑，改完更新回子库，旧的差量预览失效（**继承的，这一票一行没动**，见下）
- [x] 移除一条规则能撤销
- [x] 只用于浏览的分面不写进规则，屏上说明

收挂单 `Q873`：浏览屏左栏最底下那块「存成子库」（名字、目标路径、按钮；票 09 照稿缩成小号留着，拿主意的人 2026-09-14 定）等这一张的「加入子库…」弹层做出来之后搬走。
