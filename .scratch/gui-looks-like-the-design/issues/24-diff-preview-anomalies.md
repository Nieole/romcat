# 24 — 差量预览里的异常项与落点撞车

**What to build:** 维护者在同步前看到**差量预览**：新增、删除、保留各多少，以及处理不了的
那几类分栏列出来——设备上缺失、被修改过、目标位置被占用、**放不进目标**。他能决定要不要
补回缺失的文件，也能在**落点撞车**时排除其中一份让另一份正常复制。

**Blocked by:** 20

**Status:** ready-for-agent

⚠️ **差量预览是同步的前置条件，不是可选功能**（词表）。生成预览只读，不写任何文件。

⚠️ **撞上的一个都不放行**（词表**落点撞车**）：放行其中一个等于由排序决定谁留下，
下一趟排序变了赢家就换人。「放不进目标」一栏同时收超过单文件上限与文件名不收的字符。

- [ ] 三方对比的数字齐（新增 / 删除 / 保留 / 异常 / 放不进目标）
- [ ] 四类异常分栏列出，每一类写明工具**不会**做什么（不覆盖、不删除）
- [ ] 设备上缺失的可以选择补回，**默认不补**
- [ ] 落点撞车列出撞的是哪两份，排除其中一份后另一份正常复制，排除记为手动例外
- [ ] 放不进目标一栏含撞车、超单文件上限、文件名不收的字符三种
- [ ] 选择集改动后预览失效；同步按钮在没有有效预览时按不下去
- [ ] 「装不装得下」与子库屏说的是同一个数（`one-criterion-per-thing/01` 那个底），两处不许各算一份
