# 14 — 作品详情页六个面

**What to build:** 维护者双击一行（或在侧边详情里点「查看详情」）打开作品详情页：概览、
变体与文件、元数据、标题、媒体、识别依据六个面，一部作品的全部情况在这一层里看得完、
改得动。

**Blocked by:** 08

**Status:** ready-for-agent

⚠️ **输入框不放进会被回收的区域**（ADR-0005）：正在输入时不重绘那一块，否则中文输入法
的组字会被打断。

⚠️ 没有 **ffmpeg** 时视频显示占位图标并说明原因（视频本身完好、可以用系统播放器打开），
不报错、不挡住别的媒体。

- [ ] 六个面照设计稿排版；概览里有简介、基本信息、媒体、状态四块
- [ ] 每个字段显示当前用的是哪个数据源的值，并能一键改用另一个来源
- [ ] 手动改写任意字段，保存后记为裁决，重新刮削不覆盖，能撤销
- [ ] 标题集合：添加名称、隐藏、恢复；写明显示标题与排序标题是怎么选出来的
- [ ] 媒体面：没有 ffmpeg 时占位并说明；有视频时能交给系统播放器
- [ ] 识别依据逐变体列出候选、来源与置信度；能设为首选变体（记为裁决）
- [ ] 编辑中不重绘输入框（测试：连着输入不丢字）
