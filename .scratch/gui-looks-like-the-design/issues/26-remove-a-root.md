# 26 — 移除一个根

**What to build:** 维护者移除主库里的一个**根**，在按下去之前就知道代价：会从库里去掉多少
**变体**、多少**作品**会因此消失、哪个子库会少多少；也知道**裁决**、收藏与合集为什么留得住。
盘上的文件一个字节都不动。

**Blocked by:** 06

**Status:** ready-for-agent

⚠️ **变体的键是「根名 + 相对路径」**（词表**根**）：所以移除一个根只影响它自己那一支；
裁决锚在**内容锚**上，重新添加这个根之后仍旧有效——这两句要说给用户听。

- [ ] 移除前逐条说明：去掉多少变体、多少作品消失、子库少多少、导出条目少多少
- [ ] 说明裁决、收藏与合集保留，重新添加这个根即可恢复
- [ ] 要勾选确认才能按下移除
- [ ] 移除后根列表、左栏徽标与工序那几个数跟着变
- [ ] 盘上的文件没有被读写以外的任何改动（测试断言目标目录快照不变）
