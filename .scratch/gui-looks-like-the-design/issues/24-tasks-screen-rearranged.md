# 24 — 任务屏照稿重排

**What to build:** 维护者在任务屏上看到正在跑的那一趟（进度、已用、约剩、按得下停）、
等待中的队列，以及历史——历史里每一行写明四档**收场**中的哪一档，停下的那一趟写清保留了
什么、下次从哪儿继续。

**Blocked by:** 01、02、03。（截图那一条要等 `04`。）

**Status:** ready-for-agent

⚠️ **一次只跑一趟**（词表**任务台**）：它们读写同一份中立库、同一块盘，屏上把这条说出口。

⚠️ 四档收场的词由票 03 统一，这里只负责画得对：完成 / 已取消 / 部分完成 / 失败。

- [ ] 正在跑那一张卡：进度、已用时间、约剩时间、当前在做什么、停下按钮
- [ ] 等待队列可以移除某一项
- [ ] 历史四列（任务、结果、耗时、时间），结果四档逐字与词表一致
- [ ] 部分完成那一行写清留下了什么、下次从哪儿继续
- [ ] 任务跑着的时候其他屏照常用；状态栏那一条与任务屏说的是同一件事
- [ ] 没有任务时的空态；这一屏的基线图入库（票 04 之后）
