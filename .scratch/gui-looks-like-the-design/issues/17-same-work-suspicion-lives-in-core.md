# 17 — 「疑似同一作品」的判断落在核心库

**What to build:** 维护者在浏览与作品详情里看到「这两个作品可能是同一个」的建议与**理由**，
可以直接合并，也可以说「不是同一个」让它以后不再提示。判断本身**只在核心库一处**。

**Blocked by:** 16

**Status:** ready-for-agent

⚠️ **ADR-0024：一个判断只有一处实现。** 界面只展示理由并发起合并——界面里自己比一遍
名字、比一遍年份，就是第二处判断，迟早与核心库那一处漂开。

判据的三类线索（设计稿里已经写出来的）：不同数据库对同一部作品的**命名差异**、
**平台与年份一致**、**中文离线源里两个名字指向同一条条目**。阈值由核心库定。

- [ ] 判断在核心库一处实现，命令行与界面读同一处
- [ ] 建议带得出理由，屏上逐条列出来
- [ ] 「不是同一个」记为裁决，之后不再提示
- [ ] 浏览屏的「整理建议」分面按它给数；数与列出来的组对得上
- [ ] `crates/gui` 里没有新长出领域判断（测试断言用的是核心库交回来的结果）
