# 29 — 成型纠正的界面

**What to build:** 维护者纠正**成型规则**出错的地方：三张光盘被当成三个**变体**（应该合成
一个，前端用播放列表启动换碟）、一个目录被当成一个变体（里面其实是十几个各自独立的游戏）。
纠正**永久保留**，可撤销。

**Blocked by:** 27；纠正落沉淀库由 `one-criterion-per-thing/07` 提供。

**Status:** ready-for-agent

⚠️ **人工纠正聚合结果是一等公民功能**（词表**成型规则**）——不是补丁，是这套模型承认
规则会出错之后留的正门。

- [ ] 从库体检的「成型存疑」进得去，从作品详情的变体那一面也进得去
- [ ] 多碟：勾选要合成的几个变体，预览合成后的主文件与附属文件，合成后变体数跟着变
- [ ] 目录：拆成多个变体，拆开后各自参与下一趟识别
- [ ] 纠正落沉淀库、永久保留，删掉中立库重扫还在
- [ ] 能撤销，撤销后回到规则原本的结果
- [ ] 同结构的其他几组列在库体检里逐组确认，不一次性全改
