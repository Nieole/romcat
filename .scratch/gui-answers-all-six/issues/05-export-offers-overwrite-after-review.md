# 05 — 导出撞上外面改过时，给一条「我看过了，照写」

**What to build:** 维护者按下导出，撞上「外面有人动过那几份文件」时这一趟停下——**逐份点名
是哪几份**。他去看过那几个文件、确认可以覆盖之后，在界面上按一下「我看过了，照写」就重排一趟
带覆盖的活，不必回终端重敲一条命令。没人动过时导出照旧一路走完，不多问一句。

收挂单 `Q441`：界面上导出不给 `--force` 与 `--dry-run` 这两个旋钮。

**Blocked by:** 无 —— 可立即开工

**Status:** done

⚠️ **收场四档的词以票 `gui-looks-like-the-design/03` 为准**（完成 / 已取消 / 部分完成 /
失败）：本票正文里若还写着「按停了」「停在半路」，实现与断言一律用新词；那张票没有阻塞、
可立即开工，两张不排同一波。

⚠️ **默认一个字不变**：不静默覆盖。「照写」那颗**每次都要当场点**，不做成记得住的偏好——
它丢掉的是人的一次手改。

⚠️ **逐份点名是白拿的**：导出本来就一份文件一份文件地写、每写完把**底本**存进中立库，
所以「哪几份外面被动过」现成就有，**不要为它新造一套比对机制**。

⚠️ **不做差量预览。** 人拿到的是一份文件名单，看文件本身由他自己去；「让人看清那几份差在
哪儿」是另一件事的体量。**「只排计划」那个旋钮仍然不给**——工序那一行问的是「还差多少」，
一次不写盘的预演答不了它。

### Q641 — 撞上外面有人动过、有几份没写的那一趟，任务台上记的仍是「完成」

- **裁决（第五轮收口，2026-09-23）：** **岔** —— 实现走的就是条目建议的那条；追认：维持现状（2026-09-23 拿主意的人整批追认）。

- **来自：** 票 `gui-answers-all-six/05`
- **类别：** 规格没说
- **在哪：** `crates/core/src/adapter/transfer.rs` `export_task` 末尾（`report.conflicts` 非空时照旧返回 `Ok`、不报 `Handle::halfway`）；`CONTEXT.md` **部分完成**「没走完就收了场，却交出了产物」
- **为什么没停线：** 票面六条验收说的是「停下来、逐份点名、不打时刻戳」，没点名任务台上记哪一档；两条路都不违反词表。
- **这张票实际做了什么：** 留「完成」：那一趟每一份都走过了，被挡下的是**拒绝**不是**没走完**；「停下来」落在工序段那句红字、逐份名单与不打时刻戳上（`crates/gui/tests/roots.rs::停下那一趟不打上次导出的时刻_照写那一趟走完之后那一行的时刻跟着更新`）。
- **另一条路：** 有一份被挡下就报 `Handle::halfway`，任务台记「部分完成：有 N 份外面有人动过，没写」——与不打时刻戳是同一个判断，历史上一眼看得出这一趟没导全。
- **建议留哪条：** 留「完成」：部分完成那一档说的是「下一趟接着来就补得上」，而这几份再跑一趟平常的导出**永远**补不上，要的是人去看——拿同一个词说两件事，任务台上那一档就读不出「按一次就好」了。
- **谁来裁：** 拿主意的人
- **状态：** settled（第五轮收口，2026-09-23，见顶上裁决）
