# 05 — 导出撞上外面改过时，给一条「我看过了，照写」

**What to build:** 维护者按下导出，撞上「外面有人动过那几份文件」时这一趟停下——**逐份点名
是哪几份**。他去看过那几个文件、确认可以覆盖之后，在界面上按一下「我看过了，照写」就重排一趟
带覆盖的活，不必回终端重敲一条命令。没人动过时导出照旧一路走完，不多问一句。

收挂单 `Q441`：界面上导出不给 `--force` 与 `--dry-run` 这两个旋钮。

**Blocked by:** 无 —— 可立即开工

**Status:** ready-for-agent

⚠️ **默认一个字不变**：不静默覆盖。「照写」那颗**每次都要当场点**，不做成记得住的偏好——
它丢掉的是人的一次手改。

⚠️ **逐份点名是白拿的**：导出本来就一份文件一份文件地写、每写完把**底本**存进中立库，
所以「哪几份外面被动过」现成就有，**不要为它新造一套比对机制**。

⚠️ **不做差量预览。** 人拿到的是一份文件名单，看文件本身由他自己去；「让人看清那几份差在
哪儿」是另一件事的体量。**「只排计划」那个旋钮仍然不给**——工序那一行问的是「还差多少」，
一次不写盘的预演答不了它。

- [ ] 导一趟 → 改掉盘上那一份 → 再导：这一趟**停下来**，并**逐份点名**是哪几份被动过
- [ ] 屏上有一颗「我看过了，照写」，按下之后那几份**真的被写过去了**
- [ ] 那颗按钮不记状态：下一次撞上同样的事，还要人再点一次
- [ ] 没人动过任何文件时，导出一路走完，**不多问一句**、不多一次点击
- [ ] 停下那一趟**不打「上次导出」那个时刻戳**（只写了一半说不上导过了）
- [ ] 「照写」那一趟走完之后，工序那一段导出那一行的时刻跟着更新
