# 01 — 换工作目录与选第一个根都不必再手打路径

**What to build:** 维护者在**开场**上换**工作目录**、或者在认领新**主库**的向导里选第一个根时，
按一下就弹出系统目录选择器挑，而不是把一条 10 TB 盘上的绝对路径手打进单行输入框。
取消选择器什么都不发生。**输入框留着**——它是对话框弹不出来时（远程会话、缺桌面组件）的退路。

收挂单 `Q387`：开场换工作目录只能贴路径，没有目录选择器。
**已收**：两处各一颗「选择…」弹系统目录选择器（`rfd`，薄层在 `crates/gui/src/pick.rs`），输入框都留着；
`Q387` 原正文（`.scratch/gui-self-sufficient/issues/03-opening-lists-and-opens-a-catalog.md`）末尾补了「已落地」。

**Blocked by:** 无 —— 可立即开工

**Status:** done

⚠️ **接缝已裁定**：把那个对话框关在一个**只负责「弹一下、交回一个可空的路径」**的薄层里。
**那一层不测**（系统模态窗口测试驱动不了）；拿到路径之后的一切走**现有那条贴路径的路**，
它已经有测试盖着。别为这一件加第二条处理路径的路。

### Q691 — 目录选择器同步地弹，对话框开着时背后那扇窗停在那一帧

- **裁决（第五轮收口，2026-09-23）：** **岔** —— 实现走的就是条目建议的那条；追认：维持现状（2026-09-23 拿主意的人整批追认）。

- **来自：** 票 `gui-answers-all-six/01`
- **类别：** 规格没说
- **在哪：** `crates/gui/src/pick.rs` 的 `directory`（`rfd::FileDialog::pick_folder`）；两处调用在 `crates/gui/src/opening.rs` 的 `workspace_ui`、`crates/gui/src/claim.rs` 的 `root_ui`
- **为什么没停线：** 两条都站得住，差在对话框开着那几秒背后那扇窗重不重画；拿到路径之后那一半（`Screen::picked` / `Wizard::picked_root`）两条路一模一样。
- **这张票实际做了什么：** 同步：在画帧那条线程上等对话框关上再返回，这一帧停住。任务台上跑着的活在自己的线程上照跑，只是进度条要等对话框关上才重画。egui 仓库自己的选文件示例也是在画帧里同步调 `rfd`。**predicted**：对话框在三个平台上真弹得出来、macOS 上不撞 winit 的事件重入——测试驱动不了（票面裁定那一层不测），本机也没开窗点过。
- **另一条路：** 异步（`rfd::AsyncFileDialog`）：起一条线程等对话框，交回来的路径经通道送回，下一帧收，窗口照常重画。
- **建议留哪条：** 同步。对话框开着那几秒背后那扇窗不重画、也不响应点击，看得见的代价是进度条几秒不动（**predicted**，没开窗点过）；异步那条背后那扇窗照常重画、（不递父窗口时）也照常收点击，于是要在开场与向导上各多攒一份「对话框还开着」的状态，还得回答「对话框开着时人在背后按了『算了』、或者换了工作目录，交回来的路径落到哪儿」——而开场与向导正是 `gui-looks-like-the-design/04`、`05` 要重写的地方。真嫌停帧再换，改的只是 `pick.rs` 与两处调用。
- **谁来裁：** 收尾
- **状态：** settled（第五轮收口，2026-09-23，见顶上裁决）
### Q692 — 选根那个对话框的起点：「上次选过的位置」就是选根那个框里眼下那一串，不另记、不落盘

- **裁决（第五轮收口，2026-09-23）：** **岔** —— 实现走的就是条目建议的那条；追认：维持现状（2026-09-23 拿主意的人整批追认）。

- **来自：** 票 `gui-answers-all-six/01`
- **类别：** 规格没说
- **在哪：** `crates/gui/src/claim.rs` 的 `Wizard::root_pick_start`；规格 `.scratch/gui-answers-all-six/spec.md` 第 171 行只说「上次选过的位置，没有就用工作目录」
- **为什么没停线：** 只影响对话框从哪儿打开，不影响选中之后发生什么。
- **这张票实际做了什么：** 框里那一串是一个目录就从那儿打开，否则从工作目录。选中那一下落进的正是这个框，于是「上次选过的」白拿；框里是人自己贴的目录也从那儿打开。向导收起（「算了」、开场换目录）就跟着忘掉。**没有测试**：起点是递给对话框那一层的入参，测试看不见。
- **另一条路：** 另记一份「上次选过的目录」——在内存里挂在开场那一屏上（跨几趟向导都在），或者落盘到工作目录的界面偏好里（跨启动都在）。人把框清空、改打别的字之后照样记得。
- **建议留哪条：** 这条。添加主库一年做不了几次，跨向导、跨启动记住它换来的很少；落盘还得再兜「那块盘这次没挂上」一层。`gui-looks-like-the-design/21` 挑子库目标目录若要跨启动记住，到时在它自己那边记，不影响这一处。
- **谁来裁：** 收尾
