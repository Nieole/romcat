# 02 — 界面上的识别用上库里已经付过钱的答案

**What to build:** 维护者在界面上跑一趟识别，中立库里**已经问过、已经付过钱**的那些模型答案
照旧折成候选——与他在终端里跑同一趟得到的候选一样多。这一趟**一个网络请求都不发**。
跑完那份报告说得出「有几条候选来自已经问过的答案」。

收挂单 `Q418`：界面上的识别整层关掉模型推断，连库里已经付过钱的答案也不用。
（已收：`.scratch/gui-self-sufficient/issues/06-stages-section-and-identify.md` 那一条补了「已落地」。）

**Blocked by:** 无 —— 可立即开工

**Status:** done

⚠️ **核心库一个字都不改。** 那个装配用的结构体字段全部公开，命令行本来就是字面量构造的，
界面照它办即可——**不要加「只用缓存」那种新构造器**。

⚠️ **上一轮否掉这一条的理由在这条路上不成立，别照抄。** 挂单原文写的是「价钱要从价目表里查，
而界面上没有那几个旋钮；0 价算出来的计划会印出花费 0.00 美元」。命令行那条拒绝拦的是
**印一份计划**；界面这一路**既不排计划、也不装那个把计划念出来的回调**，于是零价永远不会
被人看见。**价目表不装，价钱一律传零。**

三样必须一起钉死：不给凭据、不排计划、不装念计划那个回调。三样缺一样，这张票就没做对。

- [x] 预先往中立库里放几条已经问过的答案，在界面上跑一趟识别，那些答案**折成了候选**
  - 证据：`crates/gui/tests/roots.rs` 的 `问过的答案::库里已经问过的答案_界面上跑一趟识别照旧折成候选`。假服务器替命令行问过一趟（两个变体，每条两个候选），界面上跑一趟识别之后，两个变体各有 2 条模型推断候选。改动之前实测是红的（`left: 0, right: 2`）。
- [x] 同一趟里**一个网络请求都没发**（不给凭据这一条在测试里断得出来）
  - 证据：`问过的答案::界面上那一趟一个请求都不发_没问过的那个照旧没有答案_零价不上屏`。`Catalog::model_spend` 前后都只有问过那一趟的一笔账，答案条数不变；问过之后才扫进来的那个变体一条模型推断候选都没有。
  - 三样（不给凭据、不排计划、不装念计划的回调）连同价钱传零，钉在 `crates/gui/src/stages.rs` 的 `tests::识别那一层只用已经问过的答案_不给凭据_不排计划_不装念计划的回调_价钱传零`。变异检查：把 `model_layer` 改成 `planning: true`，这条就红（「界面这一路排了计划」）。
  - 保留：界面这一路手里根本没有网络句柄，那条集成测试改动之前也是绿的。真正咬得住「三样缺一样」的是那条单元测试。而它验的是装配函数交出的字段，与规格「不验内部状态」相顶，记在挂单 `Q752`。
- [x] 屏上或报告里说得出「有几条候选来自已经问过的答案」
  - 证据：`问过的答案::跑完那句回执说得出几条候选来自已经问过的答案`。工序段那句回执多出一行「4 条候选来自已经问过的答案（2 个变体），这一趟一个请求都没发。」，改动之前实测是红的。数取自识别报告里按数据源分的模型推断那一行（`IdentifyReport::sources`；核心库本来就数着，没改核心库），是整库口径：接着上一趟算的那一趟不重算已经有候选的变体，只数这一趟现折的会少报。按停那一趟（部分完成）的回执也说这一行，与跑完那一支共用 `crates/gui/src/stages.rs` 的 `paid_answers_line`。
  - 保留：按停那一支没有单独的测试。按下停的时刻钉不到一个可数的信号上，而规格不许靠挂钟。
- [x] 同一份库上，界面这一趟与命令行那一趟给出的候选**一样多**
  - 证据：`问过的答案::同一份库上界面那一趟与命令行那一趟折出的候选一样多`。同一份盘上的中立库，先跑界面那一趟，再照命令行那一副装配跑一趟：三个变体各几条、报告里的候选总数、模型推断那一层的条数，三样全等（模型推断都是 4）。
  - 保留：`romcat-cli` 没有库函数可调，界面测试也够不着 `romcat` 二进制，所以命令行那一趟是照 `crates/cli/src/main.rs` 里 `model::Guessing` 那段字面量抄的（价钱查内置价目表、念计划的回调装着、上限照各开关的默认值一格一格折）。日后命令行那段改了，这条不会跟着红。
  - 提问指纹前提：界面取 `DEFAULT_MODEL` 与 `Limits::default()`，测试拿命令行各开关默认值折出的上限去问答案。变异检查：把 `model_layer` 的力度换成 `low`，`问过的答案` 那四条全红。拨过 `--model-id` / `--model-effort` 问出来的答案界面上用不到，记在挂单 `Q751`。
- [x] 核心库的公开面一个字没动（不新增构造器、不改那个装配结构体）
  - 证据：`git diff --stat 236d29f -- crates/core crates/cli` 为空。界面照命令行那样用字面量装配（`crates/gui/src/stages.rs` 的私有函数 `model_layer`）。
- [x] 价目表在界面这条路上一处都没读；零价不会被印到任何人眼前
  - 证据：`grep -rn Pricing crates/gui/src` 零处；单元测试断言价钱是零、核实日期是空的。在 `界面上那一趟一个请求都不发_…_零价不上屏` 里，没问过的那个变体让核心库照零价算了一份计划，屏上一处「美元」都没有。回执只数候选，不提计划与花费。
  - 保留：「屏上没有美元」那一句改动之前也是绿的，界面源码里本来就一处都不画计划与花费。它是护栏，防的是日后有人把那份零价计划画上屏，不是这张票改出来的。
