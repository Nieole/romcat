## 对设计的影响

这张表**不描述用户的库**。拿它推过的四条（条目量级、中文占比、街机与 PS1 的分量）已从这里删掉：
`docs/library-facts.md` 开头写着首次库体检（2026-08-31）的实测取代一切基于全站分布的判断，
其中街机与中文占比两条在它「被推翻的判断」里逐条记着。
还站得住的只剩下面两条，它们说的是这个站点怎么分类，不是用户的库有多大：

1. 站点把「中文」标为 **「官中+汉化」**——这是两种性质完全不同的东西，见 ADR-0012。
2. 存在大量**非标准条目类型**需要建模：DLC（PSP 260 / XBLA 225 / Wii 2863）、UnDUB（PS2 53 / 3DS 35）、体感游戏、minis、DSiWare、FDS、Mega-CD、WiiWare、VC。
