## 对设计的影响

1. **条目量级是 7 万而非 3 万**。十万行表格是真需求，不是假想。
2. **中文条目仅占约 9%**。这与用户「大多是各种汉化版」的自述不符，说明用户库的构成与全站分布不同（用户可能只选下中文部分）。是必须由库体检确认的头号问题。
3. **街机 12522 条是第二大集合**（仅次于 PS1 的 10384）。此前判断的「街机优先级很低」需要重新评估：条目数很大，但它没有汉化版、元数据由 `mame.xml` 直接提供，单位处理成本反而最低。
4. **PS1 官方 10384 条是最大的单一集合**，而 PS1 靠 `SYSTEM.CNF` 序列号识别可靠、实现简单，是投入产出比最高的平台之一。
5. 站点把「中文」标为 **「官中+汉化」**——这是两种性质完全不同的东西，见 ADR-0012。
6. 存在大量**非标准条目类型**需要建模：DLC（PSP 260 / XBLA 225 / Wii 2863）、UnDUB（PS2 53 / 3DS 35）、体感游戏、minis、DSiWare、FDS、Mega-CD、WiiWare、VC。
