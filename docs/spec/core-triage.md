# 待确认（`triage`）

**职责**：等人裁的东西的集合，以及人怎么批量裁它。它是工具的主界面：候选那一档是置信度不足的结论，标题那一档是一串没人裁过的中文叫法。进不进队列看**有没有自动通过、有没有人裁过**，不看置信度高低。

**边界**：队列本身不落在任何库——它是从「识别结论 + 沉淀库已有的裁决」折出来的。裁决写进沉淀库（`core-verdict`），这里不另存一份。

## 分批的形状

- **依据形状**是分批的键：整批通过时人验证的正是那句共同的**依据**（出自哪个源、撞的哪份 DAT、什么置信度、按哪套哈希口径、几个候选）。这个键只有一处算（`adr-0024`）。
- **一批变体**（屏上一级分组，还没落库）与**一批裁决**（一次批量裁决落下的那些，撤销以它为粒度）是两样东西；按下「全部通过」那一刻一一对应。
- **细分**按目录 / 按候选作品 / 按命名规律再切；切出来的那几份里，已经整批裁过的叫**一部分**，屏上看得见、点不动了。**只要还有一部分裁过，细分轴就锁死**——换个轴再切，两套切法会重叠，屏上的数当场变成假话。
- **先放着**与**跳过**不是一回事：先放着一个字都不写库（下一轮还会撞见），跳过是一档识别结论。

## 合并作品与疑似同一作品

- **合并作品**落成的是一批裁决（每个归入的变体一条），能在**裁决记录**里整批撤销；发行版信息一个字不动。它与**收敛**（导出时并成前端的一个条目）是两件事。
- **疑似同一作品**只发现并建议，一条都不自动合：两个作品得共有至少一个平台，并且至少有一条立得了案的线索（归一后同名，或中文源里同一条目）。同一串字底下挤着八个以上作品时整堆不提——那不是命名差异，是一堆两两成对。人说过「不是同一个」的那一对住沉淀库自己那张表，从此不再提。

## 已知局限

**合并之后，新扫描到的同类变体不会自动归入**（2026-09-13 裁定暂缓，访谈确认）：合并记在每个变体的内容锚上，要真做到得在沉淀库里新增一条作品级的记录。
