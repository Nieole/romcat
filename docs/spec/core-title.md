# 标题（`title`）

**职责**：三件事——**折**出标题集合、**挑**出显示标题、**另行生成**排序标题。

**边界**：不判这是什么游戏（`core-identify`），不判谁先启动（`core-adapter` 的首选变体）。它只对已经挂在作品或发行版上的那批叫法做工。

## 标题永远是集合

一个作品或发行版的全部叫法，每条带语言、地区、来源与类型（官方名称 / 译名 / 别名 / 汉化组译名）。**集合落库，显示标题不落库**——它是集合的投影，挑哪一个取决于导出到哪个前端。挑早了，跨格式互转与按中文搜索这两件事就都做不了了。

## 挑与排

- **显示标题**按 中文译名 > 官方英文名 > 日文原名 > 文件名。标题来源与首选变体无关：标题始终优先取官中的官方译名（`adr-0012`）。
- **排序标题**单独生成：中文显示标题按码位排等于乱排，所以走拼音首字母或官方英文名。它不是显示标题的副产物，是另一列。

## 不从文件名剥

汉化组与第几版**不从文件名剥**——文件名里剥出来的那一截只拿去剥**正题**。拿它当汉化组就成了「谁做的汉化」的第三个答案，与「这是第几版」同一个道理（`adr-0024`）。要的答案只有两个来源：导出时写进去的值，或者裁决。
