# romcat（命令行）

**职责**：后台入口与换一台机器时的入口——挂后台跑很久的活，以及在这台机器上跑不了的整趟工序（`adr-0023`）。17 组子命令，每组都 `--help`。

**边界**：和界面一样只调核心库，一条领域判断都不长在这里。命令行裁的与界面裁的必须是同一批（`core-runtime` 的**现场**类型就是为这件事）。

## 形状

一个 `clap` derive 树，`main` 先装中断处理（Ctrl-C → 取消令牌），再一个大 `match` 分派到各组自己的 `run_*`。共用参数用 `#[command(flatten)]` 收成几组（调优、命名规则、数据源、清单、格式、输出），于是每条命令的 `--json` / `--quiet` / 明细导出长得一样。没有 lib target：它的测试是 `crates/cli/tests/` 下的集成测试。

## 输出与退出码

- **给人看的结果走 stdout，诊断与回声走 stderr**（比如「以上出自中立库某某，没有读过主库」）。
- 退出码三档：成功、失败（`fail` 打到 stderr）、**被打断**（130）。扫描被中断时走的是 130 而不是失败——它留下了断点，那是下一趟接着跑的依据（`core-scan`）。
- 结构化输出与完整明细各有自己的开关，不塞进人看的报告。

## 两个入口的分工

**不在命令行里补**界面上已经有的能力，也不在界面上补命令行已经有的——两边都调同一处。命令行新增一条能力时，先问「这属于自足那六步里的哪一步」，属于就得同时给出界面上的落点，否则那是缺陷（`adr-0023`）。
