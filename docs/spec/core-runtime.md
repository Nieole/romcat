# 运行支架（`workspace` + `site` + `task` + `stage`）

**职责**：四件让命令行与界面能共用同一套账的事——工具自己的东西住哪（**工作目录**）、一份能干活的三样东西怎么一起开（**现场**）、一趟长活怎么报进度与停下来（**任务**）、这个库每道工序还差多少（**工序**）。

**边界**：一个领域判断都不做。它归纳的是「谁在跑、跑到哪、还差什么」，不是结论本身。

## 工作目录

中立库、沉淀库、DAT 库、中文离线源、媒体池、断点、界面的版式偏好全在这儿，**一样都不落在主库里**。位置按 `$ROMCAT_HOME` → `%APPDATA%\romcat` → `$XDG_DATA_HOME/romcat` → `~/.local/share/romcat` 这条链定，也可以每条命令单指。

**必须在本机**（`adr-0009`）：外置盘不常挂载，中立库若跟着盘走，盘不在时连浏览元数据都做不到。换一个工作目录等于换一整套工具状态，主库一个字节都不动。

一份主库一份中立库；文件名既留原目录名（人认得出是哪块盘）又带**化开之后的绝对路径**的哈希（两块盘最后一级同名时不会互相覆盖）。

## 现场

一份开好的中立库、一份沉淀库、以及这份主库的**主库标识**——三样捆成一个类型。理由很实：一条路径锚记的是「主库『某某』里的某某变体」，谁自己另起一个标识，谁裁出来的那批锚就与别处对不上。命令行裁的界面看得见，反过来也一样，靠的就是这一个类型。

## 任务台

一条队列、一个正在跑的位子、加跑完留下的历史；**排在台上的一次只跑一趟**——这些活都在读同一份中立库、写同一块盘。

**「能停」比「能取消」严格**：停止还要求停下的地方是干净的，下次接着跑不重做已完成的部分。会写东西的活被叫停时照旧要收完（清单、断点），所以有**部分完成**这一档（`adr-0015`）。

## 工序

扫描、识别、刮削、整理标题、裁决、导出六道，一道一行，显示的是**还差多少**而不是上次几点跑的——加了一块盘重扫之后那个数自己会涨，人不必自己推理「是不是该重跑识别」。**每道工序等自己的前置**，前置没做完那一行说「等待某某完成」、不给按钮。

算不出「还差多少」的那几支退回显示**时刻**（整理标题与导出的数只有跑一遍才算得出来），这是退路不是本意，度量真做出来时换回报数。这四样都归核心，界面只画（`adr-0024`）。
