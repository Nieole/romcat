# 本地数据源（`dat` + `zh` + `titledb` + `sources`）

**职责**：三份**本地镜像**——DAT 库、**中文离线源**、Switch TitleID 库——加一份「它们现在是什么状况」的结论（下载了没有、多少条、什么时候下载的、各家按什么许可给出来）。

**边界**：只提供弹药，不下识别结论（`core-identify`）；不刮削在线元数据（`core-scrape`）。这一层是识别的下半截，与「磁盘上有什么」分得很清：中立库记磁盘，这里记世上有什么。

## 三份镜像不是同一种东西

- **DAT 库**：Logiqx、MAME software list、GoodNES/GoodDB 几族格式的读法，加一个按哈希查的索引。MAME XML 是街机那一支的权威源（`adr-0010`）。
- **中文离线源**：本机一份中文条目索引加交叉校验的模糊匹配。它是识别的倒数第二层——前面几层靠字节，到这一层只剩文件名，而中文在 No-Intro / Redump / TOSEC 里一个字都没有。
- **TitleID 库**：Switch 那一层的依据，**它不是 DAT**——那个每日镜像里的 334 份 DAT 全查过，Switch 命中 0 个。所以它单独一份、单独一个来源。
- 三份都是「下载一次用很久」，各是自己的工作目录里的一个库文件，各自迁移；`sources` 把三份的读法拼成一句话，界面与命令行不各写一份。

## 取数纪律（运行时闸门）

这两条不是风格偏好，违反任何一条都会造成实际损害：

1. **绝不直连 `datomatic.no-intro.org`**：一次参数畸形的请求就触发过永久 IP 封禁，解封要发邮件求人；它的 `robots.txt` 声称允许抓取，**不可作为安全依据**。No-Intro 的 DAT 一律走官方打包出来的镜像。
2. **Redump 走 `redump.info`**，绝不碰冻结的 GitHub 镜像；列目录用 `git/trees?recursive=1` 并检查 `truncated`。

用户可以把**整份数据源清单换掉**，所以闸门是**运行时**的纯函数，挂在计划时与发请求前三处（`dat::guard`）。清单本身也是数据不是代码（`sources.toml`）。

## 已知局限

- **NDS 没有中文汉化 DAT**，中文离线源也盖不全它——24 个平台里中文覆盖面最大的缺口之一（访谈确认，2026-10-05）。
- 在线源赌的是账号与 IP（`adr-0007`）：默认限流，未识别的变体一个请求都不发。
