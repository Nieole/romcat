# Triage 标签

技能用五个规范角色说话。这张表把角色映射到本仓库实际使用的标签字符串。

本仓库的跟踪器是本地 Markdown，**没有真正的标签系统**——角色字符串直接写在每个工单文件的 `Status:` 行里。

| 技能里的角色 | 本仓库的字符串 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要人工评估 |
| `needs-info` | `needs-info` | 等报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已完整描述，可交给 agent 独立完成 |
| `ready-for-human` | `ready-for-human` | 必须由人来做 |
| `wontfix` | `wontfix` | 不会处理 |

右列现在与左列相同。要换成自己的叫法，改右列。
