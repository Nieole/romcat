# 发行版这一层有一道世代裂缝：官中在数字世代不另成发行版

ADR-0012 定过「官方中文版是发行版，民间汉化版是变体」，依据是官中有自己的官方序列号、会被 Redump / No-Intro 正常收录。这在卡带与光盘世代成立——PS1 的 `SLPS`、PS3 的 `BCAS` 都是独立序列号、独立哈希、DAT 里独立一条记录。

**但它在数字世代不成立。** Switch 的实测数据：官中覆盖 8,447 个 TitleID，而**港服与美服 69.4% 共用同一个 TitleID**。中文在那里不是一个独立发行版，而是同一发行版下的**语言属性**。

## 决定

模型跟着现实分层，不强求统一：

- **有独立序列号的世代**：官中是**发行版**，和日版、美版平级。
- **数字世代**：中文是同一发行版的**语言属性**，不另成发行版。

## Considered Options

- **一律当发行版**（给数字世代的中文版造虚拟发行版）：模型统一、下游无需分支，但库里会出现现实中不存在的发行版，且发行版与 TitleID 的一对一关系就破了——而 TitleID 正是数字世代唯一可靠的识别锚点。
- **一律当属性**（把老世代的官中也降级）：模型最简，但与 No-Intro / Redump 的现实冲突——那里亚洲中文版确实是独立记录、独立哈希，降级会让精确哈希命中的结果无处安放。

## Consequences

- **识别管线要按世代分派**：老世代靠序列号区分中文版，数字世代靠 TitleID 加语言字段。
- **显示标题的取值路径也随之分叉**（ADR-0012 定了中文标题优先取官中的官方译名）：老世代从「那一条官中发行版」上取，数字世代从「同一发行版的中文语言字段」上取。
- 这道裂缝是**现实的裂缝**，不是模型的缺陷。任何试图抹平它的设计都会在某一侧撒谎。
