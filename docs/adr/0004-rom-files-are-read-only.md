# v1 对 ROM 文件只读

识别对汉化版是有损的（见 ADR-0002），而重命名、移动、去 header、重新压缩这些「整理」操作不可逆、作用于 10T 真实数据，且会打断其他设备上前端已记录的路径。拿一个可能错的识别结论去改真实文件，是这个项目里唯一能造成真正损失的动作。因此 v1 只写元数据文件与媒体目录，ROM 文件一个字节都不改。

## Consequences

- 文件名混乱不靠改文件名解决：前端显示什么由元数据里的 `title` 决定，文件叫什么无所谓。整理文件的实际收益远小于直观感受。
- 去重只做「发现并报告」，不做「自动删除」。
- 整理能力不是永久放弃，而是排在识别质量被实际验证之后。放开时必须配套：干跑预览、仅限高置信条目、可撤销日志。
