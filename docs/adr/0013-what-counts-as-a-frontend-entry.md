# 前端条目的边界：能否独立运行，而非目录名

资源站的分类名会骗人：「XBOX360 XBLA DLC全集」「Wii DLC+WiiWare+VC全集」是混装的——`XBLA`、`WiiWare`、`VC`、`DSiWare`、`minis` 全都是独立可玩的数字发行游戏，只有真正的追加内容（剧情包、曲包、角色包）才是附属物。因此判定依据是**能否独立运行**，绝不能按目录名一刀切。

## 决定

- **真正的追加内容挂在所属作品下，入库但不导出为前端条目**。入库是必须的：磁盘上有这些文件，去重要认得、库体检要能报告、而且 DLC 必须落在正确位置模拟器才认。但让用户在电视前翻到一个点不动的「追加任务包 03」是纯噪音。
- **子平台独立成平台**：`FDS`(173)、`Mega-CD`(535)、`DSiWare`(1067) 在 ES-DE、Pegasus、RetroArch 里本来就是独立系统，用不同的核心与 BIOS。并入母平台会让启动配置出错。
- **UnDUB（日配回填版）就是变体**，现有模型装得下，不引入新概念。

## Consequences

- 「附属内容」与 ADR-0010 的「非游戏资产」（MAME BIOS/device）是两个不同的状态：前者有自己的名字与元数据、归属某个作品；后者没有名字、不归属任何作品、纯粹是运行依赖。两者都入库、都不导出。
