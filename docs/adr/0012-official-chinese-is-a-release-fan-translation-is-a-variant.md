# 官方中文版是发行版，民间汉化版是变体；首选启动优先汉化，标题来源优先官中

中文资源被资源站统一标为「官中+汉化」，但两者性质完全不同。**官方中文版是原厂发行的一个地区版本**，和日版、美版平级，有自己的官方序列号（PS3 的 `BCAS-` 即亚洲中文版），会被 Redump / No-Intro 正常收录，**精确哈希能命中**。**民间汉化版是变体**，改过字节，对不上任何官方数据库。

这个区分直接改变工作量估算：PSV(492)、XBOX360(331)、3DS(306)、PS3(282)、PS2(276)、WIIU(137) 这些现代平台的「中文」里官中占相当比例，全部走精确哈希、不进队列。真正难啃的汉化版集中在 FC(1475)、NDS(735)、GBA(572)、GB/GBC(385) 这些老平台。

## 决定

- **首选启动文件**：汉化 > 官中 > 日版 > 其他。
- **标题来源**：官中的官方译名 > 社区译名。**这两条链路必须解耦**——即使首选启动的是民间汉化版，中文标题仍取官中版的官方译名，绝不用汉化版文件名里的名字当标题。

## Consequences

- 首选启动文件通常是置信度最低的那一个（汉化版走队列，官中版哈希直接过）。这抬高了裁决队列的价值，也意味着「首选」这个属性本身需要能被裁决修改。
